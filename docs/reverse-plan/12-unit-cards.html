01任务卡通用模板（全部单元共用）

任务卡中的取证清单、第一动作与退出判据是计划动作（独立编排），不是原厂源码确认结论；不得与证据四态混用。

必填字段

  • objective
  • sourcePaths
  • actions
  • deliverable
  • operationCheck
  • exitCriteria

退出判据

  • 对该具名单元已取得可定位原源码/CIL/资源/二进制证据及明确调用/数据流边界；独立格式和审计工具按其本地源码规范。非整包源码全覆盖。
  • main已交付该具名单元的实现或该计划明确要求的可执行逆向/验收工具；仅文档、接口请求、统计台账不算实现。独立重构与VM等价分开。
  • 已有该单元的操作或交付检查通过记录，且无已知反例否定该单元；原方法合成输入不得替代真实窗口/SDK。历史记录未在本次审计重新运行。原机差分另列。
  • 源码判据、实施判据、验证判据各有台账证据，且差分与 unknown 未被抹平。

产出

  • main已交付该具名单元的实现或该计划明确要求的可执行逆向/验收工具；仅文档、接口请求、统计台账不算实现。独立重构与VM等价分开。
  • 证据卡：源路径、准确成员、证据类型、已确认行为、重建行为、未知项、操作级验证

操作级验证

  • 已有该单元的操作或交付检查通过记录，且无已知反例否定该单元；原方法合成输入不得替代真实窗口/SDK。历史记录未在本次审计重新运行。原机差分另列。
  • 历史记录未在本次复跑的须注明未重跑；失败分支与反例不得被覆盖
取证清单模板（每张卡按单元专属字段执行）
#动作
01确认原件身份（路径 / SHA-256 / MVID）与所属程序集
02定位具体类型、成员、绑定、命令与事件，记录准确源码路径
03补齐全链：入口→绑定/命令→状态读写→事件/回调→持久化或执行效果→异常/清理
04核对 CIL / 汇编 / ABI 与寄存器活跃性，消除反编译歧义
05保留操作级验证记录与失败分支；历史未重跑的记录注明
06把未取得的函数体、资源或运行证据登记为 unknown 并给出 REA 补证目标
证据不足时只登记缺口与下一步取证动作，不以合理设计填空。
