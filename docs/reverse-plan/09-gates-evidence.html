02验收分级

L1 / L2 / L3：范围逐级扩大，人工主机验收单列
等级名称范围产出
L1报告级只复算台账、校验页面链接与哈希，不运行程序。复算报告与差异清单
L2自动级在 L1 基础上运行已有的自动化检查与构建，记录退出码。构建日志、测试输出与失败项归因
L3全量级在 L2 基础上启动当前构建到交互桌面，按操作级验收逐项对照。可视窗口证据、操作记录与人工结论

03阶段门禁矩阵 G1–G8

任何单元退出前逐条对照
门禁名称规则
G1分母冻结任何页面数字必须来自机器台账；分母或排除规则变化必须提升 schemaVersion 并登记原因。
G2证据四态每个结论标注四态之一；缺失证据标 unknown，不得以用户反馈或截图代替规格。
G3调用链闭环入口→绑定/命令→状态读写→事件/回调→持久化或执行效果→异常/清理，缺一段不算闭合。
G4原生 ABI包装器只改写 RCX 时须检查 RDX/R8/R9 活跃性并记录真实入口寄存器，不采纳伪代码签名推断。
G5独立实现隔离独立实现与源码确认的结论分开陈列，不能从测试通过推出行为等价。
G6整工具计分工具完成按整工具源码级重建 + 自审计，人工验收单列，不参与完成度。
G7操作级验证每单元保留操作级验证记录；历史记录未在本次复跑的须注明未重跑。
G8确定性重跑站点不写 wall-clock；输入哈希与 HEAD 构成 builtFrom，重跑字节一致。

04单元证据卡模板

  • 调用链闭环（G3）：入口→绑定/命令→状态读写→事件/回调→持久化或执行效果→异常/清理，缺一段不算闭合。
  • 源码层判据：对该具名单元已取得可定位原源码/CIL/资源/二进制证据及明确调用/数据流边界；独立格式和审计工具按其本地源码规范。非整包源码全覆盖。
  • 实施层判据：main已交付该具名单元的实现或该计划明确要求的可执行逆向/验收工具；仅文档、接口请求、统计台账不算实现。独立重构与VM等价分开。
  • 验证层判据：已有该单元的操作或交付检查通过记录，且无已知反例否定该单元；原方法合成输入不得替代真实窗口/SDK。历史记录未在本次审计重新运行。原机差分另列。
  • 状态策略：done / partial / blocked / not_started / unverified / failed，不给 partial 折半
  • 验证新鲜度：第二十批最终170项main自审核（Group57、Host89、scope8、配置close16）；修前8项unsafe机制单列不计修复。A标准WPF11项是原绑定歧义取证，不是产品实施。既有CS8603保留；原SDK/设备/长稳差分未知。
每张证据卡必须保留：源路径与准确成员、证据类型、确认的行为、重建的行为、未知项、操作级验证；测试通过不能推出行为等价。
