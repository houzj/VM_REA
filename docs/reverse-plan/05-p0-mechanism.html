04共享约束

  • 三层判据 · 源码：对该具名单元已取得可定位原源码/CIL/资源/二进制证据及明确调用/数据流边界；独立格式和审计工具按其本地源码规范。非整包源码全覆盖。
  • 三层判据 · 实施：main已交付该具名单元的实现或该计划明确要求的可执行逆向/验收工具；仅文档、接口请求、统计台账不算实现。独立重构与VM等价分开。
  • 三层判据 · 验证：已有该单元的操作或交付检查通过记录，且无已知反例否定该单元；原方法合成输入不得替代真实窗口/SDK。历史记录未在本次审计重新运行。原机差分另列。
  • 状态策略：
    • done 本具名单元达成，计1
    • partial 有子集成果，但本具名单元未全达成，计0
    • blocked 有明确缺少条件，计0
    • not_started 未取得本单元交付证据，计0；不推断全程序不存在
    • unverified 未取得操作结果或证据不足，计0
    • failed 存在明确失败/反例，计0
  • 验证新鲜度：第二十批最终170项main自审核（Group57、Host89、scope8、配置close16）；修前8项unsafe机制单列不计修复。A标准WPF11项是原绑定歧义取证，不是产品实施。既有CS8603保留；原SDK/设备/长稳差分未知。
