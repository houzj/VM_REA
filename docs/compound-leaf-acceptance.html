# Region / Components 复合字段映射与运行验收

## 原生证据

见 compound-leaf-sources.json 的本地路径及 SHA256。Blob XML 中 BlobNum、Area、TotalArea、CentroidPoint、BlobRect 是独立输出，Components 是本项目的聚合数据名称，并非原生同名类型。RegionCopy XML 中 ROI/ROIAnnulus 明确列出矩形和环形的叶字段；本项目 Region 是最多16个 ROI 定义的托管容器，不是原生区域句柄。

VmIODecorate.LeafIOs 调用 GetAllLeafIO 并选择 Name；DisplayChildrenCommandExecute 打开 ShowChildWin。其 XAML 是370×420的只读 TextBox 列表、居中模态窗口、取消隐藏。恢复版本 IsShowChildButton 固定 false。没有证据支持新增可见的原生子字段按钮，所以本批不臆造这个入口。订阅选择器中的多级分支为独立实现，不能称为完整原生控件模板。

## 当前实现

CompoundOutputFields 是框架的托管投影层，保留原始根输出，为节点描述符增加可选叶端口，执行器发布相同路径的数据。普通连接、订阅和 Group 输出通过已有类型检查读取这些端口；基础类型叶数组使用已有 Group 累积链，不把 Components 或 Region 强行转换为 pointset。

- Components：BlobNum、TotalArea、Area、CentroidPoint.CentroidX/Y、BlobRect.RectPoint.BlobRectX/Y、BlobRectWidth/Height。
- Region：同类、非排除、像素坐标矩形映射 ROI.DetectRectCenterPoint.DetectCenterX/Y、DetectWidth/Height/Angle；同条件环形映射 ROIAnnulus 的中心、内外半径、起始角、扫角。
- 不公开投影 CircleFind 中标为 Visible=false 的中心/半径字段，也不凭项目Point2成员臆造通用原生叶端口。原有根类型及累积继续保留。
- 订阅选择器按端口完整路径建立层级，确认后保留完整路径和数组形态，单选不会同时选择兄弟字段。

Region 的不同原生形状在描述符中作为可选叶端口；运行时仅发布可完整表达的同类形状字段。订阅缺失叶会按现有 unavailable 路径失败，不能静默使用0或上次值。根 Region 始终保留，原有 ROI 算法传输不改变。

## 精度与语义边界

当前 Component 的整数包围框按 max-min+1 计算宽高，这是独立算法约定，不是已验证的原生差分结论。原生 float 叶在本项目仍采用既有 double 传输，未复现原生内存ABI或float舍入。Perimeter、方向包围框、轮廓等当前数据没有的信息不填伪值。Region 混合类型、Polygon、排除域、Fixture/Normalized变换叶、根复合混合报告模式和全部原生控件模板仍未闭合。

## 验收方式

数组专项包含真实执行器中的叶数组订阅求和、矩形/环形字段和不支持坐标拒绝投影。调用专项使用实际 BMP → threshold → components → Group 的两轮面积叶累积，核对叶总数和面积总和，并保存重开再次执行。WPF专项显示真实选择器、展开层级、选择完整叶路径、确认后读取类型并生成测试侧截图。截图仍需人工查看；事件检查不等于原生鼠标差分验收。

最新实际结果以 framework-acceptance.html 及其证据文件为准。本批没有宣称 Region/Components 全类型或原生模板完整还原。

并行证据复核补充：RegionCopy原生输出ROI/ROIAnnulus声明IsArray=false，而Blob相关字段声明IsArray=true。本项目Region容器支持多ROI，因此投影使用数组是托管列表聚合策略，并非原生固定基数还原。不得据此声称原生标量/数组ABI一致。

接口传播复核额外修复：Group根复合输出改名或删除时，同步其全部派生叶引用（连接、订阅、接口、变量和中断操作数），避免旧路径残留。实际BMP运行新增改名后父流程TotalArea读取和删除清理检查。

## 并行集成后的边界修复

- 投影前先校验模块根输出，投影数值异常记录为节点 InvalidOutput，不让整个执行器失去隔离，也不泄露半截叶数据。
- 当前 Annulus 掩膜为整环。只对起始角0、跨度360的canonical整环发布角字段；非默认角形状不投影，不把未执行的扇环描述成实际结果。
- Group 的 Region/Components 输出类型可添加，根输出来源使用源确认的32宽链按钮、180×180订阅树、打开刷新、单选叶双击提交。正文索引树因缺少原生索引元数据未补；其他类型仍使用既有选择入口，完整双Popup/全模板复刻未完成。
- 小地图依ZoomArea源码补Shift横滚、Ctrl+Shift先横滚后缩放、Ctrl-only不吞事件、零delta不推进刻度。独立操作检查走实际WPF路由；不等同真实桌面鼠标差分。
