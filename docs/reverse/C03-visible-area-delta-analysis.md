# C03 原厂 SDK 与 VM 可见面积差

已捕获的原厂 SDK 结果为 47 个 Blob、总面积 973202。VM UI 可见结果为 45 个 Blob、总面积 971486。前三行的对齐如下。

| 行 | SDK 面积 | VM 面积 | VM−SDK |
|---|---:|---:|---:|
| 0 | 718420 | 716928 | -1492 |
| 1 | 252568 | 252375 | -193 |
| 2 | 428 | 428 | 0 |

总面积差为 -1716。SDK 47 个面积向量中没有任意两个面积恰好相加为 1716，因此当前差异不能简化为“VM 只过滤掉两个完整 Blob”。前两大连通区域本身的面积也发生变化，证据更接近输入像素、ROI/Mask 或边界连通处理差异。该结论是差分观察，不指定尚未取得的具体公式。
