# C03 原厂 SDK 低阈值边界差分

固定 `ThresholdType=2`、高阈值 150、极性 0、8 连通、MinArea 10，对 `LowThreshold=98..102` 做有限差分。

| LowThreshold | Blob 数 | 总面积 |
|---:|---:|---:|
| 98 | 36 | 990400 |
| 99 | 37 | 982077 |
| 100 | 47 | 973202 |
| 101 | 52 | 963681 |
| 102 | 57 | 953693 |

没有一个值匹配 VM 的 45/971486。单像素低阈值变化会同时显著改变 Blob 数和总面积，当前 VM 差异不能由低阈值 ±2 的简单偏移解释。
