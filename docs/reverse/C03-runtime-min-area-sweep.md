# C03 原厂 SDK 最小面积边界差分

在同一原厂 SDK、`1.jpg`、阈值 100/150、极性 0、8 连通和最大面积不变条件下，测试 `MinArea=10/11/12`。

| MinArea | Blob 数 | 总面积 |
|---:|---:|---:|
| 10 | 47 | 973202 |
| 11 | 43 | 973162 |
| 12 | 38 | 973107 |

VM UI 显示的 MinArea 是 10，且运行结果为 45/971486。公开 SDK 的面积过滤在 10 到 11 之间直接从 47 跳到 43，不能解释 VM 的 45。该差分进一步排除了简单的最小面积参数偏移。
