# 逆向中间产物存储规则

并行逆向只允许保留可复核的最终证据和必要的短日志。原厂安装目录中的 DLL、SDK 和样本只保存路径、版本和 SHA-256，不复制到工作区。

每个子任务使用独立临时目录。任务完成后删除 Ghidra 临时工程、导入副本、PDB/cache、截图序列和重复日志，只保留最终 JSON、源级报告、必要的原始缓冲区和哈希索引。单个任务的临时目录上限为 512 MB，C03 当前批次新增证据上限为 2 GB。超过上限时先清理临时文件，再继续任务。

`analysis/full-audit` 中已有的原始审计材料属于历史证据，清理前必须保留其索引和哈希。新增任务不能把整个原厂目录或完整 Ghidra 工程再次写入工作区。

## Git 分支和 worktree 约束

本地逆向任务固定使用当前 `main` worktree。任务期间不创建新分支，不创建临时 worktree，不自动 cherry-pick 或合并其他 worktree。现有 `tool-plugins` worktree 保持原状，按 AGENTS.md 不修改、不清理。并行只表示同一对话中的独立只读取证任务，所有写入仍由主任务串行完成。
