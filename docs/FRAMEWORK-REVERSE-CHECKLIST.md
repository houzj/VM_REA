## 验证方法

- events：实际WPF窗口/控件事件及部分内部处理函数调用，含真实数据运行；不等于桌面鼠标输入
- visual：人工查看重建程序渲染截图，检查文字、布局与预览；不是原VM截图
- desktop：本轮重试截图FrameArrived超时，添加流程点击coordinate input geometry is unavailable；后续观察foreground window did not report a process id。桌面输入未通过
- native：本轮没有原VM同状态运行对照；既有120组扫描线样例差分范围不能外推

## 修复与复验

- 状态提示与流程耗时紧贴；StatusText右侧12像素间距；修复后截图目检分离；独立布局修复
- Group双栏根容器透明且前景未明确，渲染黑底及文字不可读；内容根容器明确#f2f3f5背景；前景#4c4c4c；修复后表头、数据源、类型与关联文字可读
