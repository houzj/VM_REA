## 90°候选的实际参数来源

80a7f0调用80ac20时尺寸packed `0xc8000000c8`，即200×200；80ac20按float*.5截断拆四象限，局部图100×100，stride100（80ac20.c的uStack_5d8/uStack_5d4与870b90调用）。870b90先执行前定位6eea70，只有pre-status1才调用6a3a70；中心来自`iStack_e0/iStack_dc`两整数，再分别float转换打包。优化72b170只在定位成功时写`peakX*d,peakY*d`到int输出，当前d1。当前有效中心为图内整数，复演使用其0..99×0..99的包含域，未预置任意小数中心。

70f4e0当前slot2=0，外层一次；对本次前定位中心，不进入后续圆拟合结果反馈产生的新小数中心轮次。δ=float(2π/30)，初中心角`θ0=−float(.5*δ)`；窗口方向`ω0=float(θ0−π)`。中心循环角在方向2时从`float(ω0+π)`开始逐次减δ，窗口方向独立逐次减δ。因此不能用`ωk+π`代替实际centerAngle，也不能直接k*δ重算。

独立最近偶数算术复演在k7得到centerAngle≈−1.5707964897155762、windowAngle≈−4.71238899230957；窗口长宽经6c9d90为42×6，中心为float(precenter +29.5*cosf/sinf(centerAngle))。6bc000再用该float中心转double计算首角：

```
x0=windowCx−21*cos(windowAngle)+3*sin(windowAngle)
y0=windowCy−21*sin(windowAngle)−3*cos(windowAngle)
```

这些是6b7ea0相位门的具体实参。全内/触边标志不替代相位门，两者都依赖角点，但用于不同分支。

## 相位门的汇编与复演结果

6b7ea0汇编1806b809f取首角X（RSP+1e0）到XMM6，1806b80fa取首角Y（+1e8）到XMM7。两轴均先CVTTSD2SI截断整数，再double相减，CVTSD2SS成float残差。不是对rectangle中心检查，也不是对角度检查。

原始残差r=v−int(v)，按float顺序折回：

```
if r < −.001: r+=1
else if r > .999: r−=1
pass iff −.001 <= r <= .001
```

门常数实际float值为−0.0010000000474974513、0.9990000128746033、0.0010000000474974513、1。X门失败跳回通用LAB_1806b8ade；Y门在1806b8151..8161也以COMISS/JA回通用；两门通过后1806b816f才比较bucket90，并在1806b8600调用CPU分类器。

独立复演使用宿主math sin/cos后按float转换，枚举全部10000个整数前定位中心：X相位约[−7.87e−6,−4.05e−6]、Y相位约[0.49999994,0.49999997]，两门同时通过0例。例precenter(25,25)：窗口中心约(24.99999428,−4.5)，首角约(27.99999403,−25.50000004)，X通过、Y失败。

静态几何解释为29.5半径、偶数6高/42宽与整数前定位中心使该角的首角Y保持约半整数；相位距.001门约.499，不是临界一两个ulp问题。故当前参数的90°候选有明确的相位拒绝链；在所述独立复演环境下30窗都回通用旋转路径。仍不把它写成实际原厂30次分派trace，也不声称其他MXCSR/非有限输入/不同参数均排除轴核。

## CPU分派来源与执行边界

684b50入口直接调用630120；返回7、10、11进6c9d90，其他走704de0。6b7ea0轴路径也**再次调用**同一630120，未从插件参数或前定位结果读取CPU类。当前相位门失败时不会执行其90°内部那次CPU查询；上层684b50的CPU查询仍执行。

630120汇编包含CPUID叶0、1、7、0xD和Windows VerSetConditionMask/VerifyVersionInfoW查询。返回通过EBX最后移EAX，不是查询函数的BOOL原样返回：

| 分类阶段 | 汇编谓词/优先级 | 结果 |
|---|---|---|
| 首轮高优先级 | R12指向的局部byte==1 | 11（1806304ab→6de） |
| 次优先级 | RSP+26a byte==1 | 10（4b6→4c0） |
| 其后 | +267,+266,+265,+264,+263,+262依次为1 | 7,6,5,4,3,2 |
| 最低 | +261 byte或0 | 1或0 |
| 第二次Windows版本检查 | 18063060a返回非零 | 保留首轮class |
| 第二次检查返回零 | 60e起按+267..+261重分类 | 降到7..0集合 |

R12指向+26b，其值由CPUID叶7调用后的EBX低位第5位提取；+26a来自更早读出的ECX位掩码0x18000000判等。后续CPUID会覆盖栈槽、存在多个寄存器备份，报告保留精确槽位与赋值地址，不把所有class直接命名为某ISA或按本机CPU型号猜class。叶0xD/版本分支还参与特征路径；完整硬件能力策略不作为本切片产品需求。

如果相位与角度都满足90°，CPU11分到7165b0/71b390，CPU7/10分到713eb0/715250，按全内/边界条件二选一（第五切片已有体）。本次并未执行该查询，不能把“源码可分派”写成“当前图已进入”。
