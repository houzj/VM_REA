# N点标定逆向记录

本工具为独立实现 `vision.n-point-calibration@1.0.0`。实现范围及已知数值边界见下文；通过检查不代表所有原生场景等价。不进行设备测试。

## 原厂证据

- `n-point-calibration-artifacts.json` 记录安装模块、XML、图标的文件身份；`n-point-calibration-managed-evidence.json` 记录原厂托管包装层和控件证据。原厂 XML 树保留在 `Resources/NPointDefinition.json`，它是审核证据，不是运行时界面引擎。
- `n-point-module-evidence.json` 保存 103 条原厂导出方法记录，覆盖 20 个构造默认值、四项参数的 40 次边界设置、手动求解与保存；可由 Invoke-OriginalNPointModuleHarness.ps1 和 Export-NPointModuleEvidence.py 重建。
- `n-point-state-evidence.json` 为原厂模块受控实例的 23 个状态场景，保留设置、输入读取、内部角度缓冲和输出写入的有序事件。
- `n-point-file-evidence.json` 为原厂 33 次模块文件写入尝试，其中 27 次产生 XML。模块文件不是算法 SDK 的 ExportCalibFile 格式。
- `n-point-ui-evidence.json` 包含原厂 XML 解析器与合成模型的十组界面规则快照及原厂点表控件图像；不是原厂桌面完整面板截图。
- `n-point-solver-evidence.json` 为官方算法 SDK 在自有进程中的合成点集结果，数值内核单独对照验证。

原厂模块受控实例通过原导出构造函数创建，绑定正常官方算法实例，并仅替换该自有进程的输入输出及运行信息回调，退出前恢复。没有修改磁盘 DLL、授权判断或其他任务进程。完整 Platform 初始化曾返回运行环境/授权错误；受控导出方法回放不代表完整 Platform 已运行成功。

## 已实现行为

原生构造默认旋转点数 3、相对坐标 false，与 UI XML 默认不同。采集按节点和会话隔离，支持数组及标量提升、分批采样、平移/旋转边界截断、满点保留数据重算、手动点表和清空。清空保留图像角度缓冲，符合原厂成员行为。旋转点数为 0 时，原厂不读取角度数量，平移采样角度写零，即使输入提供了非零角度。

没有物理坐标输入时按原厂蛇形轨迹产生坐标。示教仅在两个已绑定字符输入精确匹配时发生，保留缺输入错误、空数组及可选图像抓拍差异。未完成时输出前缀数组及零结果，完成时切换原厂结果字段；质量状态与执行错误分别处理。

模块 XML 保留 CalibInfo、点列表、图像/物理角度、-999 哨兵、方向字段条件和示教位姿条件。27 份原厂 XML 按元素类型、字段存在性、列表长度和数值进行语义对照，排除创建时间；不声称字节相等。此项使用原厂数值结果隔离验证写入逻辑，数值求解另测。

专属窗口包含基本/运行/结果页、点与 X/Y 输入、自动轨迹、示教、文件、权重高级项、点表导入导出、执行与连续执行。数值控件和开关复用已取证资源；点表按原厂列序、颜色、行高与输入长度实现。截图辅助仅存在 tests。

## 框架调整

数值数组和标定矩阵新增显式类型，数组防御复制并限制有限值。只允许 Number 单向提升成单元素 NumberArray，不自动将数组降为标量或重解释整数。数值常量/数组常量支持订阅、持久化、撤销、当前模块自执行及工作流输入输出。矩阵契约明确为图像到物理坐标的 3×3 变换，不能当作所有标定文件的统一表示。接口详情见 CONTRACT-REQUESTS.md 的 CAL 条目；全部调整位于当前 worktree。

## 验证及边界

2026-10-17 当前 `NPointCalibration.PluginChecks` 通过 5,747 项，涵盖全部 23 个原厂状态场景（适用输出域）、27 份 XML、真实 GraphExecutor 数组/矩阵流转、保存重载及独立 WPF 交互。数值内核另对照 404 组官方 SDK 输入，其中 365 组返回矩阵，11,066 个字段检查无未预期失败；45 个已知差异字段和 788 个病态/并列索引观察完整保留在 n-point-solver-verification.json。另 20 个既有检查程序共 15,275 项通过，包含 262 项真实 WPF；全解决方案构建 0 警告、0 错误。合计 22 程序 32,088 项，不将已声明差异算成完全等价。

- 缺失订阅来源元数据的 0xe000031b 属于上游框架校验；插件缺输入对应 0xe000031c。原厂自定义输出回调失败没有字典输出等价域，回放仅验证其采集状态。
- 全部原厂桌面壳和公共订阅弹层未逐像素验证；当前配对订阅弹层及连续执行调度为独立实现。
- 点文本保留原厂 CRLF、五列和数值语法。导入按原厂逐行校验写入，后续行失败保留已写入的有效前缀。至少四个平移点的安全删除限制区别于原厂可能生成负旋转数的缺陷。
- VMX 保存配置与采样点，不宣称兼容 SOL 二进制会话；有限值校验不复刻原厂异常内存行为。
- 数值差异：六组镜像点集被强制用保持朝向的相似模型拟合，存在等优分支而原厂 float 选支不同；一组含三点共线的四点透视，原厂产生极大病态矩阵，独立实现安全报错；一组最小 Huber 系数/强制相似模型，迭代末段平移系数差约 0.00108。没有硬编码这些样本、扩大统一阈值或宣称逐 float 相等。原值、实际值、逐字段容差均保留。
- 补充 WinForms tools 截图烟测在当前离屏环境触发 GDI+ generic error，未计入上述 22 程序成功结果；已修复该检查工程的标定程序集引用并让异常直接输出，完整构建通过。实际 WPF 宿主检查通过，不能据此推断 WinForms 截图环境也已通过。
