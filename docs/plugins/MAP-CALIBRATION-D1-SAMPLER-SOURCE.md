## 起角与分派：不能按整数数学角外推

70f4e0使用float δ=2π/30；中心起角为`−(.5*δ+start)`，窗口方向起角再减π；每轮中心角与窗口方向分别**减δ**，不是由k直接乘δ重算。第四切片只给出步长/反向，本切片补上负半步起角和逐次递减，禁止以0+12k估计实际桶。

6b7ea0以float `degree=57.295780181884766*angle`，通过截断整数除360的商取余，负余数再加360；bucket=int(degree)，fraction=degree−bucket。fraction<=−FLT_EPS或fraction>=FLT_EPS则直接到通用采样；其余还检查角点相位，再按0/90/180/270分派。角点相位门是另一个必要谓词，角度满足不等于已进入轴核。

`tests/MapCalibration.NativeProbe/ReplayD1SamplerAngles.py`只用索引中的PE常数进行独立逐操作IEEE float、最近偶数舍入复演，输出`angle-source-replay.json`。复演中28窗直接满足通用角谓词；k8为78°但无对应轴核，仍回通用；k7为90°，仅为角点相位检查前候选；k22约270.000183°，已回通用。故复演支持“29通用+1轴候选”的条件结论，**不是原厂执行路径确认**，也不证明任意MXCSR下相同。需要实际原厂入口角度/CPU证据时，只对该具体疑点补trace。

## 四角、长度与状态

6bc000输入float rectangle[cx,cy,w,h,angle]，将角度和尺寸转double，调用double sin/cos。首角：

```
x0=cx−.5*w*cos(angle)+.5*h*sin(angle)
y0=cy−.5*w*sin(angle)−.5*h*cos(angle)
x1=x0+w*cos(angle); y1=y0+w*sin(angle)
(x2,y2)=2*(cx,cy)−(x0,y0)
(x3,y3)=2*(cx,cy)−(x1,y1)
```

6b7ea0检查四角严格`0<x<W−1 && 0<y<H−1`，全内标志1，否则0。尺寸`int(floatDimension+.5)`，本caller已传偶数42×6；输出packed dims单独写回。全内最终status0，触边status1；这表示裁边/路径状态，不是“1检测成功”。峰提取后来复用局部status，不能串为同一种状态。

6b7c70中心在界外→6bfe30→6c2d50（当前selector2），中心界内→6b7ea0。6c2d50伪代码sin()/cos()漏参数，汇编1806c2e45/1806c2e80..eb5确认angle由float升double后传XMM0，两次调用前均恢复角度寄存器。

## 通用优化采样：double坐标、11位整数权重

当前boundary2、fill0时，6b7ea0通用路径在四角不全内分支调用6b6290，其他边界模式调用6b6820（本caller不扩大到其他模式）。通用内部行段由6b5e30取样；caller以最多32列的块调度，行stride为输出width，尾段长度单独传递。6b5e30本身按4像素展开及余数循环，不应忽略尾项。

6b6290为每行保存有效段起止、首有效坐标；两端用6bc160判定与夹取，直接复制夹取位置的最近像素。6bc160先int(x+.5)/int(y+.5)，再分别检查x/y边界：小于lower写lower，大于upper−1写upper，返回0；区间内返回1供双线性阶段。这里upper是传入W−1/H−1的末点坐标，不是W/H的越界索引。

6b5e30双线性为整数权重。令ix=int(x)、iy=int(y)、`a=(ix+1)*2048−int(2048*x)`、`b=int(2048*y)−iy*2048`；四字节为p00/p10/p01/p11：

```
top=p10*2048+(p00−p10)*a
bottom=p11*2048+(p01−p11)*a
out=byte(((2048−b)*top+b*bottom+0x200000)>>22)
```

原源码使用32位整数运算/右移，公式仅表达当前非负有效坐标路径，不替代汇编的有符号/位宽。6b5e30横向坐标double逐次加cos/sin，结束写回行末与下一行起点（起点加−sin/+cos）。6b6290先处理边界像素和有效段末端，6b7ea0再调用6b5e30覆盖内部段；不能把整行都套作浮点双线性。

6c2d50中心界外路径则直接double坐标+float双线性权重，输出+.5再截断；boundary2两端以夹取最近点填充，中间双线性。四角全内status0，其余status1，均写尺寸。即使同属优化入口，不能把中心界外体误归为11位权重核。

## 轴候选的CPU分派与填充

在角度与角点相位均通过后，90°分支：CPU11用7165b0（非全内且boundary2）或71b390；CPU7/10用713eb0或715250。270°对应718ca0/71d780与714870/715930。6b53e0只是270°、其他CPU的fallback，不能标为当前优化7/10/11必达体。本轮取全上述体供对照，但当前算术复演的270°已走通用，不把它声称为运行覆盖。

这些轴核以字节装载/重排、块转置和scalar余数构建旋转输出，并非所有路径都再做通用双线性。带填充版本调用6ba450计算源范围与输出边界，外围以fill字节（当前0）memset；相应block余数路径也必须保留。6ba450取四角x/y最小/最大，符号相关±.5后截断，依据axis flag交换宽高含义并计算裁边长度。所有CPU轴核已取C/asm，但不同SIMD打包、尾块的逐字节同构尚未完成，不以函数名或当前成功样本推等价。

## 与普通704de0的源码映射

| 操作 | 普通704de0 | 优化入口实际体 | 结论边界 |
|---|---|---|---|
| 几何起点/步进 | float sinf/cosf和float累计；横cos/sin，纵−sin/cos | 6bc000/6b7ea0以double sin/cos和double累计 | 几何表达对应，精度/顺序不同 |
| 内点插值 | float四点双线性+.5截断 | 通用6b5e30为11位权重；6c2d50为float权重 | 有明确数值实现差别，不宣称等价 |
| 边缘处理 | 从左右两端夹取最近像素，再处理内段 | 6bc160夹取、6b6290行段；轴核可能fill0 | 按实际分支分别映射 |
| 长度 | packed输出width/height，双端/中段循环 | rounded dims、有效段/块/尾段、axis转置 | 不能仅比较总像素数 |
| 状态 | 无此采样status输出 | 全内0/触边1，后层另用峰数量/status | 不可作统一成功布尔 |
