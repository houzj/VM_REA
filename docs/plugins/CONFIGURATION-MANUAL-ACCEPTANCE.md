# 公共配置框架手动验收

使用 `tests/Launch-ConfigurationAcceptance.ps1` 启动独立验收实例；顶部橙色条应显示“插件线验收 | 公共配置框架：图像源 + 标定加载 | tool-plugins 工作树”。测试启动器在 tests 中，使用真实 MainWindow、生产模型与控件，不使用替代叶模板。

1. 当前自动打开“标定加载”：检查紧凑窗口、页签、文件项、只读数据/点列表及滚动。选择或重新选择预置的 XML，执行后检查模块结果和状态；关闭窗口后再次双击该节点。
2. 关闭配置窗，双击“图像源”：检查本地图像、相机、SDK 三种模式的显隐切换；本地模式保留预置圆形样图。相机列表允许无设备，不进行设备测试。
3. 本地模式检查目录订阅开关、目录选择、像素格式、拼接和触发字段的联动。执行使用真实流程入口；相机或 SDK 未提供输入时报错应保留真实失败，不能显示旧本地图冒充新帧。
4. 打开同一节点应重用窗口；换节点应切换；关闭配置、删除节点或切换方案后，旧会话不得继续写入。

这是本轮“公共基础链路 + 两个真实工具样本”的人工验收；不代表 N 点、所有复杂模板、ROI/带渲染宿主或 SDK 嵌入布局已闭合。原厂桌面逐像素差分仍未完成。人工确认后才进行本轮中文提交和推送，主框架按逐文件接口清单接入。
