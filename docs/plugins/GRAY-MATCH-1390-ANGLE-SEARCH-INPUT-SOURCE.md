Single-angle input writes count1/index0/groupCount1. Otherwise it clears a byte visited array, computes a float tolerance from first/last angles and count with two original constants, marks each representative, searches forward against tolerance, and limits a group to four. Exact constant bytes and unordered comparisons remain prerequisites to a product translation; no typical angle tolerance is substituted.

For each group the original trainer chooses `bf2610` if either working dimension<64; otherwise the large path is inlined in `befdc0`. `bf2610` is now recovered: actual20-argument surface, cosf/sinf, fixed-point coordinate transforms, mask-dependent selected pixels, statistics and sparse records.
