## ABI与实际不重叠区域

70d280伪代码只显示空参数，不能据此认为输出未传。汇编18070d286保存输入R9=statusPtr到R15，重排栈参数，18070d2ce调用70d2e0，18070d2d3才把EAX写到statusPtr。以W为70f4e0 workspace起点，当前最多30点：

| 70d2e0参数 | 实际含义/地址来源 | 当前所用长度 |
|---|---|---|
| p1 RCX | 收集XY，W | N*8，最多240字节 |
| p2 EDX | N，收集点数 | 当前3..30才进入拟合 |
| p3 R8 | 70f4e0栈局部3float模型，&fStack_154 | cx/cy/r，12字节 |
| p4 R9 | 外层RMS指针，经70d280第5参数传入 | float，4字节 |
| p5 stack+20 | W+0x1f80 | N个float残差 |
| p6 stack+28 | W+0x2f80 | N个byte mask |
| p7 stack+30 | 70f4e0栈7槽配置，&iStack_7c | [1,2,20,0,F5,F30,F20] |
| p8 stack+38 | 70d280局部保存的workspace指针之地址 | *p8=W+0x3380 |

这些是当前caller的指针关系，不声称任意API调用都允许或禁止别名。当前XY、残差、mask、scratch之间按地址和N上限不重叠；模型和status位于不同栈槽，RMS是独立caller指针。外层没有用statusPtr代替RMS，也没有把残差float表当mask字节表。

6fc190通过72d6b0将残差复制到scratch再做选择，输出median到70d2e0局部float；不排序或重排原残差/XY/mask。迭代开始先写绝对残差，最终又在同一p5区域写有符号残差：这是**同缓冲区分阶段复用**，不是p5/p6指针重叠。

## 首次写回与逐阶段顺序

1. model1初始代数拟合成功先写p3：半径→cx→cy（18070ec48/4e/53），随后才进入鲁棒精化。初始模型M0保存到局部cx0/cy0/r0；此时未向外部p4写迭代RMS，也尚未初始化本轮mask。
2. 初始拟合失败：18070ec66..9a清p3三float、p4 RMS、N个残差float和N个mask byte，返回0。此路径的清零不能推广到精化失败。
3. 每轮先按当前局部模型Mi重写p5绝对径向残差；median调用只改scratch。trim0不进入707470排序路径，上限FLT_MAX与cutoff取小后为5。
4. strategy2逐点写p6：残差>=5→0，残差<5→1；同时累计权重矩、接受点数、旧模型的残差平方和。满足至少3点/权重和/det/q门时才把新模型Mi+1写到**局部寄存器/栈模型**，尚未对p3再次输出。局部fStack_110用于收敛，不能把它叫外部最终RMS。
5. 退出精化后按成功标志一次写p3：成功写最终局部模型（18070e398..3a3）；失败写M0（18070e377..388），预置返回码2。不是回退到“最近成功精化模型”。
6. 然后最终遍历全部XY，用所选输出模型重写p5为有符号`distance−radius`（18070e3ce..407），只对p6==1累计平方和/数量。Nmask>=3才写最终p4 RMS（e48a..4a9）；不足3则p4=0，返回0（e42e..435）。
7. 70d280收到返回码才写外部status。70f4e0不论该码是否0，先将局部模型的cy、cx、r复制到外层center/radius指针（18070ff50..77），再做非零status时的半径门/外层退出判断。因此status0也不能推导外层center/radius必为0。

## 精化失败谓词与mask保留

当前strategy2失败有：接受点数<3、权重和<DBL_EPS、abs(det)<DBL_EPS、q<DBL_EPS。接受点/权重门跳18070e29c，det/q门经18070da62清成功标志；18070e29e首先据标志决定退出，不继续下一轮。非有限值/COMISS无序分支不在本切片作数学泛化。

失败后p3恢复M0，但p6没有恢复初始mask或按M0重算。成功时也没有在新模型Mi+1写回后再计算一次残差<5来刷新mask。mask语义始终是**最后一次精化输入模型Mi的筛选**；最终p5/RMS却围绕输出模型计算。这个时序可以造成mask与输出模型的阈值分类不一致，是源码确认行为，不据常见拟合习惯补一次过滤。

当前trim0使`cutoff<=lastThreshold`的相等分支跳过后续mask计数/额外trim段（18070e3b5..c2→e3c7），因此这里没有隐藏的重新判点操作。其他trim/strategy路径不扩展。

| 当前路径 | 模型p3 | mask p6 | 最终残差p5/RMS p4 | 返回 |
|---|---|---|---|---|
| 初始拟合失败 | 全0 | 全0 | 全0/0 | 0 |
| 精化退出成功 | 最终局部模型 | 最后轮输入模型筛选 | 围绕最终模型重算/保留mask上的RMS | 通常1；半径门可2 |
| 精化失败，最后mask>=3 | M0 | 最后轮mask | 围绕M0重算/同mask上的RMS | 2 |
| 精化失败，最后mask<3 | M0，仍保留 | 最后轮mask | 围绕M0重算/RMS0 | 0 |

半径门只把非零候选状态改为2，不清模型/残差/mask/RMS。70d2e0 nominal30/tolerance20门和70f4e0 lo10/hi50门是不同层；80ac20还有独立[15,21]半径门，不可合并成同一个status判定。

## 失败回退中数据是否“别名”的结论

当前没有证据表明mask/RMS/模型物理地址互相覆盖。此前未决点主要是反编译局部变量和输出缓冲复用导致的**语义时序**：fallback只恢复模型，保留最后mask；残差从绝对值改成有符号值；最终RMS按保留mask重算。汇编确认恢复p3后直接进入最终残差循环，并读取同一个mask地址(RSP+288)，未调用median或阈值重建。

这闭合当前caller的地址、首次写回、失败回退与最终RMS选择。未执行失败原厂微探针，未声称任意输入数值结果等价；若后续需补证，只需构造当前strategy2的一次精化失败并记录上述缓冲区写序。S1索引不变、S2有限推进完成，产品/S5/S6未变。
