## 固定相同坐标，隔离11位权重量化

把两公式都固定到首点double坐标(75.53693952279573,47.70487205422865)，不允许几何/累计参与对照。float权重wx≈0.4630604684、fy≈0.7048720717；整数公式首次量化为：

```
a=(int(x)+1)*2048−int(2048*x)=949
b=int(2048*y)−int(y)*2048=1443
a/2048=.46337890625; b/2048=.70458984375
```

这里`int(2048*x/y)`截断生成11位权重，已与float权重数值不同。后续整数双线性和+0x200000右移22位采用第五切片取得的原公式；字节范围内本例中间值不溢出有符号32位。

四邻接字节按[p00,p10,p01,p11]取**[0,68,0,68]**（水平梯度，两行相同，进一步消除Y权重影响）：

| 同一有限输入的计算 | 输出 |
|---|---|
| 普通float几何+普通float权重 | 37 |
| 固定通用坐标+float权重 | 37 |
| 固定通用坐标+11位权重 | 36 |

未舍入水平插值约为float36.5119、量化36.4902，分居36.5两边，最终取整不同。此例说明**量化本身足以造成首点1字节差异**；不是因为换了像素格、边界填充值、累计到后续列或误用轴核。

## 哪个“首先不同”必须分开说

源码运算轨迹的首个精度不同在三角结果float/double保留；坐标累计前已出现几何差。输出差异的最小隔离反例则在同一坐标、同一像素格、同四字节条件下，由11位权重量化独立产生。没有原厂执行，因此不能据此说真实SDK某次检测已经产生相同1字节差，也不能据此开放/合并产品路径。
