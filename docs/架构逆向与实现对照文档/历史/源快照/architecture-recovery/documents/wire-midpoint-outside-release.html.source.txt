<li>源码确认：原始 <code>Connection.xaml.cs</code> 的 <code>connectionUserControl_MouseMove</code> 根据 <code>Page.Width/Height</code> 裁剪路径拖动，<code>connectionUserControl_MouseLeftButtonUp</code> 无条件结束拖动并释放鼠标捕获；没有按当前 <code>ScrollViewer</code> 可见视口取消的判断。</li>
<li>独立实现：WPF 画布鼠标松开时，对已经捕获的连线中点拖动提交最后预览路径。Esc、失去捕获以及编辑边界失效仍按已有逻辑取消。</li>
<li>验收：<code>dotnet run --project tests/VisionEditor.WireFocusChecks/VisionEditor.WireFocusChecks.csproj -c Release</code>。真实 WPF 中点柄按下、预览移动，将系统指针移到可见视口外后松开，确认单次路径事务、撤销重做及保存重开。截图 <code>analysis/full-audit/wire-midpoint-outside-release.png</code> 已目检，连线路径和箭头持续可见。</li>
<li>未验原生：真实 VM 桌面鼠标越过窗口边界后的操作差分，以及失捕事件与鼠标松开同时到达时的系统事件顺序。</li>
</ul>
