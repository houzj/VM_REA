<p>本次在 <code>WorkflowCanvas.PreviewNodeMove</code> 统一逐节点计算预览与提交位置；单节点维持既有路径。组的临时边框按全部预览节点的新外接矩形绘制。极端右边界下，原来位于 X=4550 和 X=4800 的两个宽 110 节点向右拖 200 后分别落在 X=4750 和 X=4890，这是原始逐项限幅逻辑的结果，节点间距可能缩小甚至重叠。</p>
<p>运行 <code>dotnet run --project tests/VisionEditor.MultiMoveEdgeChecks/VisionEditor.MultiMoveEdgeChecks.csproj</code>。专项通过 WPF 组边框鼠标事件启动手势，再调用画布拖动预览/提交处理器；核验两个临时节点位置与最终位置一致、一次文档事务、撤销、重做及保存重开。8 项通过。<code>analysis/full-audit/canvas-multimove-right-edge.png</code> 已目检：右侧边界处两个预览节点发生重叠，小地图可见视口移向右侧。测试未向系统注入连续鼠标移动；原生拖动临时层在边界处的每一帧视觉效果仍未验证。</p>
