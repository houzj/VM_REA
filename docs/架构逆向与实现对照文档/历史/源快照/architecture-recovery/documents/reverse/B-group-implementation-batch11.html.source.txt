<h2 id="原源码与真实缺口">原源码与真实缺口</h2><p>本批复用本地原始反编译材料，未新增 REA 调用或原厂运行：</p>
<ul>
<li><code>analysis/decompiled/VM.Core/VM.Core/VmIO.cs</code>：<code>ClearRelation</code> 查询 <code>QueryModuleIOBeSubscribed</code>，用发布字段、索引字段和模块 ID 区分引用种类。<code>case 1</code> 表示仅索引引用，只有 <code>item3.RelateIndex = null</code>；<code>case 0/2</code> 才同时清值引用。<code>OnRemoveCollection</code> 进入 <code>Dispose</code>；不将本批静态阅读冒称原生删除全链运行。</li>
<li><code>analysis/decompiled/VM.Core/VM.Core/DynamicVmIO.cs</code>：<code>OnNameChanged</code> 对 <code>nextSubIO</code> 的 <code>case 1</code> 重新设置 <code>RelateIndex=this</code>；值源与索引源身份独立。</li>
<li><code>analysis/decompiled/VM.Core/VM.Core/VmModuleSet.cs</code>：<code>ProcedurePaste</code> 实时查 <code>VmSolution.Instance[sub]</code>；Group 经 <code>Export</code>、<code>LoadGroup(...isFromCopy:true)</code> 和参数复制；复制映射建立后依次 <code>ModulePaste</code>、<code>ModulePasteFinish</code>。main 的独立 owned 图映射不能称为原 gro/native GUID 实现。</li>
<li><code>analysis/decompiled/VMControls.WPF/VMControls.WPF.DataForUI/VmGroupDecorator.cs</code>：<code>MaxLevelOfGroup=3</code> 与 <code>GetLevel</code> 的父 Group 遍历。</li>
</ul>
<p>main 原 <code>PropagateGroupInterface.Apply.Bindings.Operand</code> 在输出被移除时，无论是值源消失还是仅索引源消失都返回 null，丢掉仍有效的数组操作数。现仅值源删除时清操作数；仅索引源删除时保留 Source、Inside、Self、Constant 和 Index，只清 IndexSource。输出 rename 继续按稳定 interface ID 更新 index Port。</p>
<p>没有给删除索引强加 Index=0：原 <code>ClearRelation</code> 没有更改 Index；main <code>GroupOperand.Index</code> 虽默认 0，但已有静态值不能由默认值取代；这也与 main <code>ClearInvalidGroupBreakVariables</code> 的既有策略一致。<code>IndexSource</code> 按 main <code>GroupBreak.Validate</code> 固定引用父域标量整数，没有单独的 IndexInside/IndexKind 字段。</p>
