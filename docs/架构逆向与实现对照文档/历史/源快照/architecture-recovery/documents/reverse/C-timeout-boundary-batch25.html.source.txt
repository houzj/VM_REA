<li>同文明确记载 <code>SyncWaitor</code> 具体忙等、消息泵、超时和线程重入实现未在当前 decompiled tree；<code>IMVS_SetProcedureWaitTime</code> 是否限制流程、回调、设备任务或重入仍未知。</li>
<li><code>docs/MF05-CONTINUOUS-RUN-CALLCHAIN.md</code>：main 的 <code>StartContinuous/ContinuousRun</code> 是协作式托管循环，与 native <code>ContinousRunStart/RefreshUIStopExecute</code> 的线程、停止延迟和回调顺序不等价。</li>
</ul>
