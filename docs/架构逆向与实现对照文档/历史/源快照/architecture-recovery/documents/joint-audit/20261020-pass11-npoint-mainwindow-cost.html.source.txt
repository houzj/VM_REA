<h2 id="原版与当前路径">原版与当前路径</h2><ul>
<li>原版 <code>IMVSNPointCalibModuControl.NPointList.UserControl_Loaded → Init</code> 按 <code>CalibPointTotalNum + RotPointTotalNum</code> 建行，每行五次读值、格式化，再调用 <code>PointList</code> 五个 setter；setter 向 <code>IUserStringData[字段+ID]</code> 逐叶写。原 <code>PointList.cs</code>、<code>NPointList.xaml.cs</code> 和 XAML 的完整 SHA 分别为 <code>A396060C73DBF56B1A7FB7849A4BCD17FE5CBC3D04AD8356F68D4B3B1C9B3813</code>、<code>B972D12AF77B27DC3A19E00629C77F3BED58D3FD7A266DD0AA28050A281B5A46</code>、<code>92945CE0D5ED92F98F12187A0EB92F1673516760B894F0CD52F89FC2C7341D79</code>，原体路径见<a href="20261020-pass6-npoint-ui.html">第六轮源码审计</a>。逐叶写是原源码事实；原版的图文档历史开销和实际耗时不由该成员证明。</li>
<li>当前 <code>NPointConfigurationControls.Register</code> 的 <code>NPointEditPoints</code> 点击调用 <code>NPointConfigurationPointEditor</code>，构造器为每行五列调用 <code>commit</code>；<code>NPointConfiguration.CreateConfiguration</code> 的回调经 <code>PointValues → Apply → ToolConfigurationHost.Apply → GraphEditorDocument.SetProcedureNodeParameters → Edit</code>，<code>Edit</code> 每次 <code>RecordEditHistory</code>、<code>Revision++</code>、<code>Changed</code>。实际配置窗口的 <code>Changed</code> 进一步触发 <code>RefreshAll</code>。源码见 <code>src/VisionPlugins.Calibration/NPointConfigurationControls.cs</code>、<code>NPointConfigurationPointEditor.cs</code>、<code>NPointConfiguration.cs</code>、<code>src/VisionEditor/ToolConfigurationHost.cs</code>、<code>src/VisionEditor.Core/GraphEditorDocument.cs</code>。这整个文档编辑链是当前适配，不能移称原版必然逐次重画。</li>
</ul>
