<p><strong>判定：</strong> 开窗触发 <code>5×点数</code> 次完整图文档编辑，这一放大由源码和回调计数共同确认。耗时是单次离屏受控样本，含 JIT/WPF/机器负载；不推出真实交互桌面分布，也不归因永久卡死。表中单格并未呈随点数单调恶化，用户报告的慢可能还有配置宿主布局、其他节点图规模、历史负载或窗口事件因素。本探针没有对原版进行同机同步计时；不能报原版速度比。</p>
<p><strong>修复方向及约束：</strong> 可在插件配置与图文档之间研究保持原版逐字段 setter/失败副作用的前提下，避免开窗初始化给图编辑器建立 <code>5N</code> 份完整历史快照；但必须先核原版 <code>IUserStringData</code> 写入是否在全部初值相等、失败或重复打开时仍产生可见副作用，并定义图历史/保存的事务语义。仅凭本次成本探针不能直接删除初始化 setter 或合并成一次批写，也不能动在制 <code>tool-plugins</code>。下一步可增加真实主窗口大图历史负载的受控诊断，和原版同字段写入的 getter/setter trace。</p>
