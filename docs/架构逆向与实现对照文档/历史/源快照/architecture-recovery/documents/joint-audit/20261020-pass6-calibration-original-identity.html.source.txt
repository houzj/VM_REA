<p>原件身份：每个安装目录均实际存在 <code>ToolItemInfo.xml</code>、<code>&lt;目录名&gt;.xml</code>、同名原生 DLL 和 <code>Cs.dll</code>；四项另有同名 <code>Control.dll</code>，坐标系另有 <code>CoordinateModuleCpp.dll</code>。十份主 XML 的 <code>Base/Items/String[@Name=&#39;ModuleName&#39;]/CurValue</code> 全等于各自目录名；原 <code>ToolItemInfo.name</code> 九项等于目录名，唯标定板不同。十份原 <code>ToolItemInfo</code> 均有 <code>helpUrl</code> GUID，逐项值及原件 SHA 在 <code>identity.json</code>。原 priority 为 0–8，其中坐标系和标定加载均为 8；不自行改成唯一优先级。没有从目录名或工具箱显示名倒推原版固定数值实例 ID。</p>
<p>当前映射：<code>src/VisionEditor/tool-catalog.json</code> 工作区快照的十行 <code>Id</code> 均等于上述原安装目录；其 <code>ModuleId</code> 分别对到右列独立插件 ID。对应 ID 定义分别位于 <code>src/VisionPlugins.Calibration/NPointPlugin.cs</code>、<code>NImageConfiguration.cs</code>、<code>ReadCalibFilePlugin.cs</code>、<code>RotateCalibrationPlugin.cs</code>、<code>TranslationPlugin.cs</code>，<code>src/VisionPlugins.CalibrationBoard/CalibrationBoardPlugin.cs</code>、<code>src/VisionPlugins.CameraMapping/CameraMappingPlugin.cs</code>、<code>src/VisionPlugins.MapCalibration/MapCalibrationPlugin.cs</code>、<code>src/VisionPlugins.DistortionCalibration/DistortionCalibrationMetadata.cs</code>、<code>src/VisionPlugins.CoordinateModule/CoordinateModulePlugin.cs</code>。这些 <code>vision.*</code> 是<strong>当前重建版身份</strong>，不是原厂 XML 中的 ID 或同名 ABI。<code>HEAD</code> 的目录仅八项有非空 <code>ModuleId</code>：N图像标定、相机映射的映射来自当前工作区<strong>未提交</strong>改动，不列为已交付基线。第六轮目录宿主探针另证明当前工作区十个插件可实例化，但不证明原版运行同一性。</p>
<p>证据边界：本报告完成十项<strong>静态入口身份</strong>核对，尚未逐项核原厂 SDK 动态创建后实际数值实例 ID、工具箱点击到 SDK <code>strModuleName</code> 的每条运行态路径，亦未核十项 UI/算法与结果链。标定板 <code>ToolItemInfo.name</code> 差异尤其说明不能把三个原始标识强行视作一个字段；后续若工具箱选择失配，须以原 <code>ToolBoxItemData</code> 构造参数和 SDK 创建请求核实。以上缺口属于当前目标后续 J01/J02 与各工具独有链，不因本报告关闭。</p>
<p>复验：<code>pwsh -NoProfile -File analysis/joint-audit/pass6-calibration-identity/collect.ps1</code>，逐项比对产出 JSON 的 <code>ToolName</code>、<code>XmlModuleName</code>、<code>CatalogId</code>、<code>PluginId</code>、哈希和 DLL 存在性；脚本仅读安装件与当前目录，将 JSON 写到本线忽略证据目录。本次 <code>identity.json</code> SHA-256 <code>57AADBBE06D6B47153DC88CD7F234E44F32871D917454A731D1AE449C384E561</code>；<code>collect.ps1</code> SHA-256 <code>F9C0A74C6E0C1AC22E15CD50DF037D969511627AFEB5ABBF8CBB959A71AFF7DE</code>。</p>
