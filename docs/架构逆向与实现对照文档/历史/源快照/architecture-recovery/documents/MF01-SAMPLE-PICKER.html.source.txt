<h2 id="独立-wpf-实现和验收">独立 WPF 实现和验收</h2><p>文件菜单“打开示例”现在先显示 Windows 文件选择框，默认从随包示例目录或上次选择目录开始；取消不更改文档，选择有效文件后记住目录、执行未保存方案确认、加载方案并刷新最近方案。启动时演示方案的自动加载继续保持，不触发选择框且不污染最近列表。目录偏好独立保存在 <code>%LOCALAPPDATA%/VisionEditor/sample-directory.txt</code>。</p>
<p>专项 <code>VisionEditor.ShellChecks</code> 显示实际 WPF 主窗口并点击菜单，通过可控的选择器返回随包真实 <code>demo.vmx.json</code>，验证初始目录、加载后的实际 <code>doc.FilePath</code>、最近菜单首项和目录文件；再通过同一菜单模拟取消，验证当前方案不变。目录文件在测试中重定向到本工作树。完整 <code>VisionEditor.WpfChecks</code> 456 项通过。</p>
<h2 id="仍待原生差分">仍待原生差分</h2><p>原版 WinForms 通用对话框筛选 <code>.sol</code>；独立项目使用 Windows WPF 通用对话框与 <code>.vmx.json</code>。专项自动验收覆盖实际 WPF 菜单和加载结果，但系统文件选择框的像素外观尚未单独截图对照真实 VM，不能宣称该子窗口完全一致。原版通过配置 INI 记住目录，本项目使用独立文件。</p>
