<h2 id="目标树元数据与待验证差异">目标树元数据与待验证差异</h2><p>ImageSource 随包 ImageSourceModuleAlgorithmTab.xml 中 <code>StitchStartHeight</code> 和 <code>StitchHeight</code> 标记 <code>CustomVisible=False</code>，<code>StitchEnable=True</code> 触发器再通过 <code>VisibleOperation</code> 显示它们。原始对象模型也把 <code>NameValueItem.CustomVisibleA</code> 与 <code>SubscribeVisibleA</code> 分开：后者另受 <code>CanSubscribe</code> 和所属 <code>Category.SubscribeVisibleA</code> 控制。因此，主框架不能把“隐藏”和“不可订阅”混为一种布尔值，也不能按 <code>Stitch*</code> 参数名硬编码特例。当前 <code>ParameterDescriptor</code> 没有表达参数可见条件/订阅显示状态，主线的类型筛选只能构建静态列表。</p>
<p>VM源码 <code>DynamicNameValueItemOfGroup.OpenDialogCommandExecute</code> 先调用 <code>IGroupRunParam.SupportDisplayForGroupData()</code>，再回退到 <code>GetSupportDisplayForGroupData()</code>；<code>DynamicExtern.cs</code> 为 ROISelecter 创建 <code>ROISelecterForGroupDecorate</code>，XAML 的 <code>ROISelecter_GroupControl</code> 再映射到 <code>ModuleROIConfigControl</code>。本框架当前未复刻这条原生装饰器/模板链，属于插件-facing契约 FCR-018，和可见性差异FCR-019均仍未闭合。</p>
<p>已将该跨线契约记为 <a href="CONTRACT-REQUESTS.html#fcr-019-%E5%8F%82%E6%95%B0%E7%9B%AE%E6%A0%87%E7%9A%84%E5%8E%9F%E7%94%9F%E5%8F%AF%E8%A7%81%E5%8F%AF%E8%AE%A2%E9%98%85%E8%83%BD%E5%8A%9B%E8%AF%B7%E6%B1%82%E6%9C%AA%E5%AE%9E%E7%8E%B0">FCR-019</a>。在插件线提供经源码审计的元数据前，这一控件仍未闭合；其余静态可用整数目标已由实际流程变量订阅和运行数据路径覆盖。测试目标改用本地图像模式不影响执行的 <code>SetCameraParamWaitTime</code>，避免把 42ms 订阅值误当作 <code>Interval</code> 而改变测试运行时序。</p>
