<p>独立 WPF 实现在文件菜单最近记录之后添加分隔线和“退出”，点击时调用当前 <code>MainWindow.Close()</code>，复用标题栏关闭后的执行取消、工具配置窗口收尾和执行作用域释放。专属 ShellChecks 实际打开菜单、检查分隔结构并触发 <code>MenuItem.Click</code>，验证 <code>Closed</code> 事件和窗口不可见。</p>
<p>本项仅闭合“退出”菜单的入口与关闭生命周期；原版菜单完整顺序、禁用规则以及密码/后台运行等 SDK 退出策略未作等价声明。</p>
