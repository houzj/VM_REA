<h2 id="首差修正">首差修正</h2><p>独立 Python 将原H带入候选完整pivot逆序，九个逆矩阵float bits全相同。用原逆H和原图复演候选warp仍恰好12字节差，因此该输入不应先归罪于拟合或逆核。</p>
