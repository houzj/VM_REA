<h2 id="当前宿主-ui-装配路径代码事实">当前宿主 UI 装配路径（代码事实）</h2><p><code>src/VisionEditor/MainWindow.xaml.cs</code> 注册 12 个插件（2026-10-19加入标定板）。<code>src/VisionEditor/ToolConfigurationHost.cs</code> 的分派条件是：只要插件实现 <code>IToolConfigurationProvider</code>，宿主就直接创建 <code>ToolConfigurationModelWindow</code>；只有没有 provider 时才调用 <code>IWpfToolEditorFactory.CreateWpfEditor</code>。因此当前已注册公共模型路径包括图像源、N点、N图像、相机映射、平移旋转、标定加载、旋转标定和标定板；即便这些类型同时实现了窗口工厂，工厂也不会被这个宿主分派。当前走专用工厂窗口的是多图采集、缓存图像、光源和图像二值化。此处是本项目的代码事实，不能据此推断原厂架构也采用相同类层次。</p>
<p>畸变、映射标定项目也有配置模型提供器/工厂代码，但当前 <code>MainWindow</code> 未注册它们；全量回归覆盖其项目检查不等于产品节点已可由用户添加。标定板已从此边界移出，其真实宿主候选等待本轮人工验收。后续自检将逐项把原厂 XML/XAML/模板的实例化路径与本项目选择公共模型或专用窗口的理由对应起来，避免因“统一模板”而抹掉原厂专用行为，也避免因“专用窗口”绕开原厂共享模板。</p>
