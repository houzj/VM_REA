<h2 id="专属补丁与最小回归">专属补丁与最小回归</h2><p><code>MapCalibrationPlugin.Runtime.Image</code>将 <code>Pose(previous)</code> 改为当前帧 <code>Pose()</code>，缺少WorldRotateAngle时固定-999，去掉旧angle继承。仅改该生产路径，不修改共享NImage/Contracts或原生payload。</p>
<p>新增 <code>tests/MapCalibration.InputStateChecks</code>：每侧独立节点反复只输入一张2×2图，永不凑齐图像对，不触发检测；验证显式pose→全缺省→部分pose→漏Angle四轮、哨兵float位、无帧早返、File模式失败保留pending/pose、等待无合成display，以及XML R字段为-999。测试读专属私有session仅用于验证缓存，不向产品注入测试钩子。</p>
<p>构建采用独立 <code>analysis/map-calibration/d4-production-state/artifacts</code>，根线串行授权。最终结果与hash在同目录验证记录；首次测试编译缺System.IO已修，不隐去该失败。没有原厂运行或设备测试新增。</p>
