<h2 id="本项目实现">本项目实现</h2><p>两个插件都经 <code>IToolConfigurationProvider</code> 创建 <code>ToolConfigurationModelWindow</code>，并由公共 <code>ToolConfigurationView</code> 按原厂 XML 模型解析页签、类别、控件模板、触发器和订阅操作。旋转标定的 <code>InputWay</code> 是 XML 中没有 <code>AccessMode</code> 的 <code>RadioSelecter</code>；反编译模型在初始化阶段从 <code>IUserStringData</code> 读取 <code>Param.&lt;name&gt;</code>。公共状态模型因此允许此类单选控件写回配置用户数据，不把它误当成只读算法参数。</p>
<p><code>EditButton_Calib</code> 使用源资源确认的左标签、数字编辑器和编辑图标布局，并继续使用既有平移标定点表弹窗。其图标来自仓库现有 N 点控件资源，形状和悬停切换与反编译模板一致；没有原始 <code>Apps.XmlUI</code> PNG 资源可供字节或颜色逐像素对比。共享显示组使用本项目已实现的对象绑定、颜色选择和订阅控件；未实现或没有契约的源操作必须暴露诊断，不能伪装成已支持。</p>
