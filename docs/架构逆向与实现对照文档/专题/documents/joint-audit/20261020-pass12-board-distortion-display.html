J08 裁决及下一有限证据

当前构建的上述两条具体显示/失败/切换边可关闭。畸变失败时旧图与点 graphic 保留是观察到的当前行为；原 ProcessOutput 非原子发布路径说明不能假定失败必清空，但未直接证明原版在同一文件扩展名错误后仍显示这些旧图或点。若要判断偏差，下一步只需对原厂受控实例的同一“先成功→自动导出失败→切节点”序列记录 GetDisplayList 图层对象值/可见状态与结果回调，或通过原托管 ModuleDisplayDecorator 结果刷新调用链加受控原模块输出复验；缺这一步不得自动清旧图。标定板也需原同图 NoMatch 的记录/图层差分，以及两项当前 UI 的默认选层/人工可见呈现。原配置窗口、全部图层勾选与缩放/像素级外观不由 11 项断言覆盖。J08 两工具整门仍开放，不重复正常夹具而扩称完整审核。
