第六轮 J01/J02：标定十工具的目录、注册和实例化共享边

范围仅“标定”分类十工具；工具各自算法和编辑器运行不由这项探针验收。原版共同入口 VMControls.Data.ToolBoxData.UpdateLoad 懒读分类目录下各子目录 ToolItemInfo.xml，建立 ToolBoxItemData；其原反编译体 analysis/decompiled/VMControls.Data/VMControls.Data/ToolBoxData.cs SHA-256 C1B11D2C3BEBCE66A11769EB0E209455CB1E5D0C4EFA7C4A6DAD5992EB9CF45B。原 VM.Core.VmModuleSet.CreatModuleByInfo(IMVS_MODULE_INFO) 取 SDK strModuleName，调用 CreateModuleToolRe，AddModuleByInfo 核同名同 ID 后纳入 Modules；反编译体 analysis/decompiled/VM.Core/VM.Core/VmModuleSet.cs SHA-256 F3B98C4436686B0A9BABF8CDE4F5F6C83814664B8F7835DFABBEB02E2A64A346。十个原 ToolItemInfo、主 XML、原生/Cs 载体的静态身份已另在十项原件身份报告逐件取得；原厂 SDK 动态枚举/创建后数值实例 ID 尚未逐一核，不能由目录猜运行身份完全一致。

当前共享链：src/VisionEditor/ToolNavigation.cs 的 ToolGroups → LoadToolCategory → ReadCategoryTools → CreateCatalogTile 从分类 JSON 取工具，按 ModuleId 查已注册 descriptor 决定是否可用；MainWindow.xaml.cs 构造时逐个注册标定插件；ToolPluginRegistry.Register → ModuleRegistry.Register 校验 manifest/descriptor 身份；GraphEditorDocument.AddNode 取得 descriptor 并写默认参数。用户现有 tool-catalog.json 未提交改动使 N图像标定、相机映射两个 ModuleId 从 null 变为注册值；本轮只读这个工作区事实，没有覆盖或提交该文件。HEAD 目录是八个标定 ID，当前工作区是十个。

tests/CalibrationCatalogHost.Checks 在自有离屏 WPF MainWindow 中真实加载“标定”分类，逐项核目录 ID、插件注册、manifest/descriptor/version、ModuleRegistry.Create 运行时工厂和 GraphEditorDocument.AddNode，最后确认图中有十个唯一节点。十项全部通过，原始 stdout analysis/joint-audit/calibration-catalog-host/checks.log SHA-256 0BEB1FBB9647B008CFA18379FFE801F0612051EB0BDB9CFD58378AA13D23CEC9，逐项端口/编辑器存在性快照 catalog-host.json SHA-256 E6F1E5230863359D10A435434B07DC84CC91632D5BB348FD3826C1C739C2D3C0。快照另证十项都至少有专用 WPF 工厂或共享配置 provider；相机映射、映射标定走后者，不能因无专用工厂误报无编辑器。复验：dotnet run --project tests/CalibrationCatalogHost.Checks/CalibrationCatalogHost.Checks.csproj -c Release。首次测试因测试文件缺 System.IO 导入未编译，失败日志保留于同目录 first-compile-failed.log；随后只修测试，产品未变。这个探针验证当前工作区实例化共享边，不验证用户交互桌面拖放、配置窗、真实执行、Group/保存重开或原版逐工具身份同一性。

后续按十工具唯一归属补 SDK 动态创建、配置与算法入口，并复用已建立的标定输出→另一标定工具的真实链；共同目录加载与注册入口仅在本报告审一次。框架实施指标仍 41/96=42.71%，此次审核不增加整单元。
