IsNumber先排除非0-9.-、多dot、多minus，再要求(^([-]|[.]|[-.]|[0-9])[0-9]*[.]*[0-9]+$)|(^([-]|[0-9])[0-9]*$)。后者接受单独-；整个联合接受.5/-.5/1.5，拒绝1./1.2.3/--1/1-2/+1。候选不再用缩略regex代替。

但GetBindIndex的先后门是：非空→先Contains('.')查GetIoByPathFromAround；仅else调用IsNumber并创建Name原串的VmConstantIO。任何查找返回null，显示本地化“订阅失败”，Warning图标，然后仍return null，没有throw或回滚。

SetCombination.Operate先切掉[...]并查来源。来源不存在提前返回；来源存在且目标IO存在则先iO.RelateIO=source，随后iO.RelateIndex=GetBindIndex(...)。后一返回null时照常赋值。RelateIndex setter先UnSubscribe旧来源，SetRelateIndex(value)递归给所有Children，再Subscribe原来源。因此未找到dot路径时来源保持，索引变null/All，两叶都清掉索引。不得保留旧index、把base绑定全部回滚或报告typed decimal literal成功。

-不含dot且IsNumber为true，创建Name=-的常量。原native atoi域结果0，原串仍必须保存。DTO/primitive直接带小数原串仍可作为独立底层API适配，但不能冒充上述正常UI的常量入口。超int32拒绝仍是托管边界，未声称原C overflow等价。
