必需运行行为

外层18003f280经vtable+40调用180017a40图像前置；错误立即返回，空图E0000510、零尺寸E0000511。随后调用内层18003f4a0，不检查其返回值即调用180040550 ProcessOutput，再公共后处理。不能按其他标定工具模板把内层错误直接变成无输出。

图像前置续核：39700→38f40实际体已补（C SHA2A663475ADC0FA40D164DF02BD565F5CCC29D7A1031FD7ED65B1E8F9D6A89A10；asm SHA5D786504D4E746B35083E85D854A548AAF4624C5A0765E3D78C673FCCC1F1B56）。38f40仅四tag：01000000/01080001→mono1，02180014→packed201，02180021→planar200。已知format载荷必须等于widthheight(1或3)，不等39700返E0000314；未知tag mapper返0且不填data，17a40复制其初始化null pointer，最终外层E0000510。17a40本身还会先拒非正宽高E0000001，所以上述E0000511只是外层二次检查指令，不能当完整caller的优先码。正常owned图尺寸正且长度由构造保证；opaque Raw必须显式执行这些门。托管用long乘法避免故意32bit尺寸溢出，原不安全溢出payload不伪称完全同域。

内层先置status=0。CordinateCreate=0且ROI type12时，把this+ec/f0/f4复制到pose this+15e48/4c/50，调用180040320。CordinateCreate=1且InputWay=0/1时，按SrcPointX→SrcPointY→SrcAngle顺序GetFloat(index0)，任一非0立即返回；不检查Count，三个成功才一起写pose和矩阵。Count0成功使用预先清零的本轮局部值；不得把真实空payload失败冒作Count0成功。

180040320使用double三角计算theta=atan(1)4floatAngle/180，每个结果转换float。矩阵为 [cos,sin,-cos*x-sin*y; -sin,cos,sin*x-cos*y;0,0,1]，不是任意常见坐标变换约定。

InputWay=2：180040180先清flag；180039480读取CalibMatrix首项与Count但吞底层返回码。仅Count1..9允许，再经1800395b0原错误检查/批读覆盖matrix的前Count项；尾部保留。后调用MatrixToParam SDK，成功后取其deltaX/deltaY/theta，各用float符号位xor变负写pose；输入matrix保留，不调用CorToCalibmatrix。

MatrixToParam精确分派

被动原PE字节脚本matrix-sdk/read-vtables.py验证目标哈希并输出vtables.json。tool vtable180008928：+8→1980 GetResult，+10→1990 SetInput，+20→1be0 Process。result1800088e8：+10→1880读取+0xc deltaX，+18→1890读取+0x10 deltaY，+20→18a0读取+0x14 theta。

1e40创建algorithm handle type0x67；1be0检查9项并非全零后传Process opcode0x6b，成功复制六float并标ready。原已有core源链：1c4e0 case6b→20480→7c6ba0 mode12→7f5ca0(36/24bytes)→7efd00→800af0。7efd00先检查输入H33 epsilon，失败10000019；800af0返回不等1为1000010f。800af0原float逆矩阵、H33归一、atan2分解已由共享NPointSolver.MatrixToNativeParameters实现，复用成功路径而不再写第二套数值核。该公共API的参数/奇异错误10103002是独立安全合同，不能称SDK错误码相同。

theta是800af0的atan2结果，弧度；模块只变负，没有转degree。Draw/POINT路径的Angle则在40320按degree转三角，不能为了统一命名修正原行为。

catch、状态与发布

异常PE元数据见native-source/exception-scopes.json，专属ExportCoordinateExceptionScopes.py严格匹配目标。外层无tryBlocks。内层int handler473f0、uint4746b、IMVDException474e6、catchall475b0分别把错误写局部ret（catchall E00000FF），共同继续3fdab计时尾。尾部VM_M_SetModuleRuntimeInfo返回值覆盖局部ret，并按该返回值设置status。因此Draw无Coordinate ROI的E0000007、捕获SDK异常可在计时写成功后被覆盖成status1；普通GetFloat早return则保status0。不能用“原主伪码未含catch”推断恒成功，也不能把捕获后原错误当外层直接失败。

ProcessOutput180040550始终按顺序发布status、9float矩阵、pose原点、4float轴。XX=50m00，XY=50m01，YX=50m10，YY=50m00（不是m11）。隐藏输出仍是Display.xml的coordinate Feature来源。任何运行失败不自动清空先前矩阵或pose。原逐API输出失败可能留下部分输出，与托管字典发布边界分开。
