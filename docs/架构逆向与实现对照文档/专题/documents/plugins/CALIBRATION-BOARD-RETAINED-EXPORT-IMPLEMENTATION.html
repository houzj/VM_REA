显式Save调用链没有CreateMultipleDirectory；同一SetParam中的CalibPathName分支另有该调用。因此产品的显式保存不应复用自动路径准备而替用户创建缺失父目录。

实施：Runtime入口保留最后成功Matrix，仍清当前Outputs并捕获当前Inputs；成功时替换Matrix，失败按现有失败输出/显示门发布，绝不把保留矩阵作为本轮CalibData。Export检查原后缀门、已有矩阵，再调用不创建目录的WriteExplicit。无结果80100003、后缀e0000204、无法打开80100010使用专属IOException派生类型运输，供配置通知读取。自动CalibPathName路径准备仍保留，不将显式路径与自动路径混成一个门。

托管写/关闭失败同样安全报告80100010；原厂没有检查fwrite/fflush/fclose结果，不能称这一额外错误域原生等价。原SDK晚期结果拷贝中途失败的部分内存副作用不在本片复刻；本次具体确认的路径是算法检测失败之后，最后成功矩阵仍可显式导出。
