原Map XML ImageSource_0/1：Initers GetFrontParamItemsOperation(IMAGE)写EnumEntrys、GetSelectedCombinationOperation读InputImage1/2；CurValue触发SetCombinationSourceOperation。原Apps.XmlParser GetFrontParamItemsOperation.Operate调用VmModule.GetFrontIOWithLeafItemsByName(type)，把返回IList设置父节点TargetName+A。VM.Core.VmModule.cs4049起取GetFrontParamItems，加原global13000/localvariable，父模块输入或前序模块输出GetAllCombinationByType，过滤CanSubscribeA&&Visible，返回ModulePathName字符串。既有共享typed订阅服务承担引用身份，产品不从caption解析身份。

当前共享ConfigurationSubscriptionValidation.FromElement能读EnumerationG的该Initers，正确建立Combination/InputImage1/2及IMAGE过滤；ToolConfigurationSubscriptionControls.ImageEnumeration真实ComboBox DropDownOpened直接service.Enumerate(query)，SelectionChanged直接service.Bind+State.ApplySubscription，因此控件可独立于State.Choices运作。但Map dispatcher缺EnumerateInputs，State.Initialize原Initers先得到UnsupportedOperation。原真实Host和后注入SaveEditor都受影响；不能把它当“测试没服务”。

有限专属候选仅照已生产Board同族分支处理Map EnumerateInputs：FromElement→context.ConfigurationSubscriptions.Enumerate→Handled或明确错误；控件继续消费typed tree，不添加caption identity或第二套枚举。候选640EA2B...等根线统一短窗应用。新增真实Host测试从前序Source A/B两IMAGE候选通过真实WPF ComboBox绑定两侧，不再doc.Connect图像捷径；仍保留POINT组合、完整运行与Save/load/release断言，新增State无GetFrontParamItemsOperation Unsupported。当前新测试未构建。

再次核对原Operate写EnumEntrysA=list，单纯Enumerate后返回Handled仍丢弃结果，不能据下拉后查询成功声明Initers赋值复现。上述640EA候选仅是中间分派切片，根线将补共享typed SubscriptionTree result→State节点保存→ImageEnumeration初建加载，Board和相关provider返回原查询tree。当前源码冻结，等待根线短窗。Host已新增实际每侧下拉打开前Items含前序IMAGE A/B typed候选，再打开刷新并选择；新版未运行。原中间Host21不变，工具仍未完整。
