abs(det)和q分别受DBL_EPS门。中心/半径输出再转float；初始拟合失败会清模型、RMS和残差掩码并返回0。其他模型2/3不据名称补实现。

strategy2用绝对径向残差abs(sqrt((x−cx)²+(y−cy)²)−r)；6fc190取中位数，奇数取中间、偶数取两中间均值。72d6b0复制到scratch再调用72d110选择第k个，后者小分区(<64)插入排序、大分区选择/分割；这些只改scratch。trim0表示选择上限FLT_MAX，不能读为“残差上限0”。实际接受残差严格<5；N>3时scale=median*2.96516+eps，否则DBL_MAX。残差<scale权1，否则scale/(residual+FLT_MIN)。

加权矩重新拟合需至少3接受点、权重和>=DBL_EPS，并重复det/q门。最多20次；RMS与相对变化的1e−5条件控制继续。更新成功status1；精化失败可回退初始模型并status2。最终有效点/RMS、半径与状态分开写回；不能宣称任一失败必然清所有输出，精化/最终失败存在保留模型的路径。失败回退中残差掩码与模型的写序已由 第七切片 补核：模型恢复M0、mask保留最后轮、最终残差/RMS重算，未发现当前指针物理重叠。

当前nominal30/tolerance20产生10..50范围，70f4e0也检查半径。此局部模型门不能代替更上层80ac20的门。

修正：80ac20真正检查的是半径[15,21]

80ac20→870b90调用的stack+20是center(RSP+5f4)、+28是radius(5fc)、+30是RMS(f8)、+38诊断列表、+40点数、+48配置；870b90继续转发到6a3a70。汇编18080b4ee起从5fc取float，与PE181642ea4的15、21做COMISS/JA门。

故先前报告“质量值门”现明确修正为拟合半径[15,21]门。对普通有限值，半径通过后给center加局部象限偏移形成四点；这里未同时gate检测status/RMS。NaN的COMISS行为不能用通常数学区间替代，未执行NaN补证。6a3a70返回0表示参数接受，检测status、center/radius、RMS另传；不能把它们当同一种成功。

生命周期、严格缺口与下一步
