必须分开的边界

  1. 原图像错误实际caller顺序：39700各primitive getter先早返；已知format长度不匹配314；39700成功后17a40非正尺寸E0000001；外层3f280再查data为空510、宽高为空511。公共PortValue只接受owned Gray/Rgb/Raw，构造已要求正尺寸且包含payload，不能用托管对象伪称覆盖所有原指针/元数据同时损坏的组合。正常owned域的四tag/长度/未知tag门已按源补齐；long尺寸乘法避免故意native32bit overflow。
  2. 原SDK矩阵成功数学来自800af0并由公共NPointSolver.MatrixToNativeParameters复用。原7efd00错误10000019/1000010f与公共helper参数/奇异错误10103002不同；后者是独立安全合同，不能宣称原错误码已完全复刻。模块catch继续计时覆盖ret、保pose/新raw矩阵的外部行为另按原实现。
  3. 初始未知slot、安全zero存储不等于原heap值。省略未知矩阵/轴并诊断，全部9slot有来源后才发布；已知尾部的后续prefix继续按原保留。
  4. native非有限浮点状态可以产生，但有限PortValue不能表示。保state、不写0，省略非法叶，报NativeNonFiniteResult；这不应被写成数值成功。
  5. 原一次BatchGetFloat不是任意scope逐项回调。普通Graph immutable frame固定prefix为独立transport；有scope reader的多值批明确UnsupportedDynamicMatrixBatch，且禁止与不同c.Inputs快照混源。
  6. 普通POINT父连接投影是产品广告合同的独立兼容；不把它写成native新增的combined getter，也不吞显式叶错误。
  7. 无工具文件按钮/存储资源。普通方案保存参数、绑定、ROI和显示，关闭释放配置lease；没有把opaque native runtime heap加到自创文件格式。人工/设备/原厂桌面像素验收不计工具实施完成前置。
