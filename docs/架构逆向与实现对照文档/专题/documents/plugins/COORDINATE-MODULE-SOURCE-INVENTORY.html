Draw仅this+38==12时读取base ec/f0/f4三float为poseX/Y/Angle；Subscribe POINT/XY两模式共用SrcPointX/Y/Angle GetFloat(index0)，三个status逐项即返、Count/其值采纳门仍按实际体核。ByMatrix 40180经39480取Count，再395b0首项/批读，允许1..9；不是必须9。矩阵从this+15e20起前缀写入，其尾部生命周期须明确而不能填标准单位阵伪等价。

原常量字节：angle=(atan(1)4floatAngle)/180；matrix逐元素float存储：[cos,sin,-cosx-siny; -sin,cos,sinx-cosy;0,0,1]。不能将源double表达式随意换成另一个矩阵逆实现。输出原点取pose字段，轴向量50*[m00,m01]与50*[m10,m00]（YY确用m00，任意输入矩阵不能擅改m11）。ByMatrix调用MatrixToParam对象vtable+10输入/+20执行/+8结果，再从result+10/+18/+20取三float并逐一xor signbit；具体SDK实现尚缺，不能从惯用分解公式补写。
