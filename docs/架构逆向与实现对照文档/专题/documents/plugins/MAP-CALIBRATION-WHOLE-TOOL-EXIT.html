原生差异、实施与验收的边界

  • 采样独立算术复演不是原厂运行；负索引区间的地址关系不证明heap安全。整工具验证保留这些证据类别，不能靠测试通过抹掉未知。
  • D1/D2涉及公共NImage/NPointSolver、D4涉及公共ROI/display/session的修改统一交根线；本线只提具体成员/字段/生命周期差异，避免另建一套公共核。
  • 原源码恢复、实现映射、自动验证和自审的整工具退出由根线审计；人工验收不计入进度且不阻挡完成。生产宿主配置、双ROI交互、Image/File/Teach运行显示、保存重开/切模式/释放应有自动验证证据；用户手动验收另列可执行检查，不以局部文档交接计完整工具，也不把受控IO host当真实VM显示验收。

推荐下一顺序

  1. 根线审查本次空ROI跨轮状态，修正旧“ResetMember仅Init调用”结论；按新分支判断产品是否需要状态差异请求。
  2. 回到D1当前caller的decoder纠错/warp精确缺口，形成原卡源码退出表；D4只在其剩余具体桥阻塞整工具时补体，不继续无边界扩base/shape实现。
  3. 根线实施D1/D2必要共享差异后，以D3必要真实分支验证，并并行完成D4原资源/绑定/输出释放对应，最后作整工具审计和独立宿主验收。
