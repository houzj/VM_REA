MF-01 文件菜单资源顺序

原始 analysis/decompiled/VisionMaster.Exe.Audit/menuitems.xml 将文件菜单排为新建、打开、最近打开、打开例子、保存、另存、导出算子代码、导入流程、退出。Apps.Style/menustyle/menustyle.xaml 的 SubmenuItemTemplateKey 把 IsShowSeparator=true 渲染为当前条目之前的分隔线；资源中打开例子、保存、导出、导入、退出带此标记。

当前 WPF 壳将已有可执行命令按原始顺序排列，在打开示例、保存、退出前显示分隔线。文件菜单采用原始模板证据中的 200 宽、34 高子项和深色弹层结构；颜色是按当前壳独立映射，未移植动态主题字典。最近记录仍动态生成；点击保存、示例、打开及退出均通过专项 WPF 菜单操作复验，未改变对应数据结果。测试程序生成 analysis/full-audit/shell-file-menu.png，目检确认全部文字可读、分隔和最近打开箭头可见。尚未接入的“导出算子代码”和“导入流程”没有增加空命令，其原始位置及分隔语义留待功能实现时恢复。

本项为源码确认的相对顺序与分隔语义、独立 WPF 菜单呈现；没有宣称完整文件菜单条目、原版菜单模板像素或运行态禁用规则已闭合。
