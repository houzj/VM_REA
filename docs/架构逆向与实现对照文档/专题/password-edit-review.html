Group：密码设置、修改、取消保护与UserData

39个窗口原件方法、10个Group方法、32处挂接；空白条件按原指令保留。原BAML、运行绑定和浏览器呈现未验收。

Set CheckPassword uses exactly IsNullOrWhiteSpace(first) && IsNullOrEmpty(repeat) as nullable-null gate; otherwise direct string equality returns nullable true/false. This is not the usual either-input-empty predicate. Equal nonempty whitespace inputs reach equality, but actual UI entry is not established.

Modify has two overloads: old password is nullable-null on whitespace, otherwise equality with OriginalPassword; new pair is nullable-null if either is whitespace, otherwise equality. OK computes both before choosing blank/old-error/new-mismatch branches; only both true stores ModifiedPassword, sets isPasswordOK and closes.

Set OK stores Password and isPasswordOK=true only when helper true, then calls BaseWindow.Close. Its Cancel handler sets false and closes. Modify has no local Cancel handler; neither selected type has set_DialogResult.

Original connectors have 19 Modify and 13 Set event registrations, including OK and input handlers; no btnCancel_Click registration. BAML keys exist in original g.resources, but control/default-button/cancel mapping remains unconfirmed.

Eye setters explicitly copy between PasswordBox and visible TextBox. Preview regex/key, first TextChanged segment removal and CanExecute Handled-only behavior are local input paths, not a replacement for final helper predicates.

Group enable stores PasswordA from Set.Password then IsPasswordEnabledA=true; edit stores Modify.ModifiedPassword; disable first authenticates Check window then clears PasswordA and disables. Callers read IsPasswordOK, catch Exception and log; ShowDialog bool is not the accepted-state predicate.

Group getters read VMModule.UserData keys and refresh cached values only when bytes are nonnull. Password uses UTF8 conversion; enable uses StructToBytes/BytesToStruct<bool>. Setters change cache first, write UserData second, notify last and skip same-cache values. No local rollback or two-key transaction is present.

UserData indexer has parent/lifecycle and history branches, then SetUIParamValue selects dynamic UI or ordinary SDK setter. These paths are separate from native protected .grp export and do not establish encrypted-at-rest password storage.
