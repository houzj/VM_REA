OpenGlobalModule的11000模块非null后创建/复用通信窗，设置DecorateSource、IsGet/IsOpen、语言、owner后ShowDialog；本审计未独立确认主菜单resolver到CommSet。

SC02 · btnImport / btnExport XAML → btnImport_Click / btnExport_Click

两个Click声明均存在；IsEnabled声明绑定SolutionData.(IVMRun.IsRunning)并用BoolBackToEnable。声明不等于运行绑定证据。

GlobalCommunication import/export declaration:133

SC03 · btnImport_Click → RegisterEncryOperation(path,false) → ImportCommData

先确认和gtd文件选择；缺14200时反射创建GlobalTrigger模块。找到11000才解密所选文件、写ImportCommData、刷新通信及触发。未找到11000仍可走末尾成功提示。

GlobalCommunication.btnImport_Click:1298

SC04 · btnExport_Click → ExportCommData → RegisterEncryOperation(path,true)

路径非空且11000存在时先写ExportCommData，再加密文件；路径非空而模块缺失仍可成功提示。PathTooLongException和其它Exception分开提示。

GlobalCommunication.btnExport_Click:1409

SC05 · RegisterEncryOperation → rename original → unpack → rewrite each root file → repack

先把输入文件移动为VMExtensionTemp名称，建立临时目录；解包并处理根目录文件在try内，失败删目录并移回。成功后先删临时归档，再压回原路径；压缩不在上述catch保护内。RegisterEncryToFile先删原文件，再调InnerWriteLibFile且丢弃bool。

CommunicationEncryService.RegisterEncryOperation:12 · CommunicationEncryService.DecompressToFiles:126 · CommunicationEncryService.RegisterEncryToFile:152

SC06 · GetInnerEncryptedData / GetInnerDecryptedData → SolutionManager dongle API

加密只在bIsContainKey=true时调用变换；解密检查isEncrypted后仅看keyBuff!=null，不看bIsContainKey。检测/取key返回int被丢弃，真正变换非零才抛VmException。null数据使InnerWriteLibFile返回false；RegisterEncryToFile未读此值。

CommunicationEncryService.GetInnerEncryptedData:208 · CommunicationEncryService.GetInnerDecryptedData:176 · CommunicationEncryService.InnerWriteLibFile:236

SC07 · SolutionManager managed wrappers → ServerSDKAPI → NativeMethods.IMVS_*

keyBuff先分配16字节；加解密分别分配输入长度+84/-84的输出并pin传入。返回码非零直接return；nDataLenOut未用于裁剪返回数组。原生算法/密钥内容/设备状态/运行绑定未验证。

SEC-TRIGGER-02 · 切换方案触发配置的密码编辑、错误清空与继续下发

registered-finite-model-slice

GlobalTriggerConfigContent的PasswordBox声明Attach=True，附加Password TwoWay/LostFocus绑定SolutionPasswd。ComTriggerItem字段更改发PropertyChanged；GlobalTriggerConfig弱订阅后ValueChanged调用CheckPassword。空路径或空密码直接true；只有格式和有密码标记均1时才校验。错误nIsCorrect==0提示后置isSetChange=true并清密码，仍返回true，因此后续SetTriggerItem(Modify)可下发清空值，不能写成错误即阻止保存。ChangeSolution分支把路径及SolutionPasswd放入Load_Solution.stFilePath/stPassward并序列化，写ModifyTriggerEvent-/ModifyTriggerString-字节参数。

GlobalTriggerConfigContent password declaration:112 · ComTriggerItem.SolutionPasswd:224 · GlobalTriggerConfig.AddTrigger weak subscriptions:151 · GlobalTriggerConfig.ValueChanged / CheckPassword:191 · GlobalTriggerConfig.SetTriggerBytes ChangeSolution:506 · GlobalTriggerConfig.SetTriggerItem:609

  • UI运行附加绑定、失焦时序和实际母页实例未验证。
  • 触发模块收到字节后持久化及执行换方案的原生路径未恢复。
  • 完整GlobalTriggerConfigContent输入限制和选文件入口仍待追踪。
SEC-REMOTE-03 · 远程服务器口令RSA配置存储及设密入口未有模型引用

original-component-recovered-main-caller-unknown

本地RemoteServerVerification.SaveServerSetting调用RsaCryptHelper.Encryt(InputPasswordBox.Password)后SaveConfig(ServerPassword)。类还包含CheckServerPasswordStatus、SetServerPassword和确认事件；真实主界面创建调用链仍未定位；正式页另已核原件及选定体，此处不宣称可达。

RemoteServerVerification.SaveServerSetting:169

  • 原VisionMasterMain.dll身份和选定体已在正式页核对；真实创建者/主界面激活仍未知，不从AssemblyRef推可达。
  • 密钥提供者、实际配置解密消费者、传输验证与原机连接仍未知；选定RSA字符串包装已见正式页R10。
  • 保存成功/失败、远端状态与任务继续分支未完成逐支还原。

尚未闭合

  • Original .gtd ZIP format and entry layouts; recursion/header/empty directory behavior.
  • Actual runtime binding, route/enabled converter, module11000 parameter handlers and14200 constructor side effects.
  • Native encrypt/decrypt algorithm, dongle state/key semantics, errors, exact returned output lengths.
  • Failure recovery when move, unpack, delete, recompression or temporary path collision fails.
  • Screened files with existing ranges can still contain unmapped security branches; zero refs is not the only gap criterion.
