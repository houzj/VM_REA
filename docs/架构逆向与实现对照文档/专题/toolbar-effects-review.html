工具栏：脚本保护、异步保存与另存结果

20个聚焦方法，编译器闭包按原MethodDef token定位并校验共同TypeDef。显示名如.<>c并非完整嵌套名，精确身份以原件SHA/MVID、TypeDef/MethodDef token为准。未执行厂商代码，完整链和浏览器呈现未验收。

ToolControl owns its script-window cache; GlobalScript creates/replaces GlobalScriptUI.MainWindow, rejects nonzero GetShellParamer, reads shell password enable/value, shows PasswordCheckWindow and ignores modal bool before checking IsPasswordOK. SetWindowOwner is called before showing script UI, not before the password check in this body.

Original add/remove/add ExcuteEvent operands refer to three distinct MethodDef tokens. Their bodies all call VmSolution.Instance followed by VmModule.Run, but equal-looking lambdas do not prove removal of the originally registered delegate.

Public SaveSolution with path first Dispatcher.Invoke(SaveCalibUserData), then Task.Run re-reads VmSolution.Instance.SolutionPath and calls SaveAs(that current path,null), ContinueWith ResetParamStateFlag. That worker has no local catch; continuation body does not read antecedent Status/Exception. No path calls SaveAsSolutionProcess and discards bool.

SaveSolution(Task) is a separate overload. Worker catches Exception and logs/shows errors; continuation resets communication flag then optionally Start afterSaveTask without inspecting antecedent outcome. No-path branch starts afterSaveTask only if SaveAsSolutionProcess returns true.

SaveAsSolutionProcess authenticates existing protected solution through Decryption.ShowDialog()==true; the decryption result string is not copied into tempStrPassWord. It then resets temp password to empty, attaches encryptCheckClick to file-dialog button and shows file dialog.

Only FileDialogResult.Ok invokes SaveCalibUserData, SaveAs(selected path,temp password) and reset flag. SaveAs return value is discarded. File-dialog cancellation still reaches normal return true after disposal; auth rejection returns false earlier. No completed-save semantics are assigned to that true.

encryptCheckClick requires modal true and nonempty AccessAdministatorCode before storing tempStrPassWord; Encryption cancel is true plus empty and is filtered here. Existing solution password, newly requested file password and script password remain separate.

SaveCalibUserData enumerates VmSolution.Modules.OfType<VmProcedure> and calls IVmProcedure.SaveCalibData for each; actual calibration persistence and native SaveAs effects remain outside this slice.
