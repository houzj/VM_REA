BaseWindow：标题栏、模态、关闭与清理

19个聚焦原件方法。REA整程序集成员读取因64MiB表示预算不可用，原件身份成功；随后用静态PEReader读取所选方法，未加载厂商程序集。原BAML、运行绑定、WPF模态结果与浏览器呈现未验收。

Apps.PcUI base TypeRef resolves to VM.Controls.BaseWindow with matching selected assembly name/version/public-key token; selected SHA/MVID is recorded. Runtime assembly binding and original BAML/template selection remain unverified.

Base template declares CloseWinButton with visibility TemplateBinding. OnApplyTemplate finds named parts then attaches Click to closeBtn_Click. Constructor separately registers CloseWindowCommand. Both handlers call BaseWindow.Close; this is separate from password Cancel handlers and Window.DialogResult setter.

BaseWindow.Close is a new virtual member. If _isclosed it returns; otherwise sets CloseReason numeric 3, calls Window.Close within catch(Exception), whose handler writes ex.Message. This body does not set DialogResult or password fields.

OnClosing calls Window.OnClosing first, checks e.Cancel and returns if cancelled. Otherwise writes _isclosing=true, hides owned windows only when loaded and visible, then activates nonnull Owner. It has no local catch or rollback.

OnClosed sets closing state, removes from ActivatedWindows under lock, calls base.OnClosed, then sets _isclosed=true. It detaches selected current template-part handlers, attempts owner foreground activation, and only if _hs exists removes hook/disposes it, clears owner and stops optional closeTimer. A null _hs skips that final cleanup block.

ShowDialog is a new virtual wrapper: closing gate returns nullable false, then modal flag/reason state. Depending on Owner/Application/thread it may set native custom owner, or use visible LastWindow/MainWindow and clear a cross-thread owner, before Window.ShowDialog. Actual WPF modal result semantics remain outside this body.

ShowDialogDelay updates or creates DispatcherTimer, removes/adds Tick handler, marks auto-close and starts timer before base dialog. Tick calls Close only when not already closing and stops timer in finally. Password callers in mapped slices use ShowDialog, not a proven timer path.

OnApplyTemplate registers state/mouse/size/button/Loaded handlers with no corresponding pre-detach in that body. Loaded callback measures header/button sizes, raises minima by Math.Max, then calls OnLoaded. Repeated template and old-part lifetime remain unverified.

WindowProc handles close-reason messages separately from Close(): source records messages 17/22 as shutdown, 274 SC_CLOSE as user, and 16 as task-manager reason only when prior reason is None. This code does not prove the real external source of a close request.

边界

  • Original BAML/style selection, inherited WPF DialogResult/Close internals and actual modal/focus dispatch.
  • Owner/native handle/foreground effects, cancellation exceptions, repeated template application and cleanup after partial failure.
  • ActivatedWindows predicate closure and every external caller; timer-to-password-window reachability is not established.
  • No original window, password/SDK, native message injection or desktop operation was executed.
