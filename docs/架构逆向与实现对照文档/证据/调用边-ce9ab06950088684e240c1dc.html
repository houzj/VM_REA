MODULE样式AttachedRoutedEvent.Event / OnEventChanged → RoutedEvent依赖属性 → 当前事件非null才AddHandler

选定Apps.UIHelper原件的Event属性以RoutedEvent类型RegisterAttached，默认null，元数据回调指向OnEventChanged。回调通过GetEvent读取当前值，null直接返回；否则将目标as UIElement，对该RoutedEvent AddHandler(Control_MouseDoubleClick)。本体不按字符串反射事件，不读取OldValue，也没有RemoveHandler；不能把事件改名/置null描述成已经解绑旧处理器。Command与CommandParameter分别以ICommand/object类型注册附加属性，默认null，由Get/SetValue访问。WPF资源确实引用该程序集名，但实际加载副本未运行证明。
