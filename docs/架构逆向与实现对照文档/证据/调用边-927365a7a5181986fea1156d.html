ICommand.Execute(object) → Base.Execute / 同步适配 → async void → Task包装 → Action调用 / 异常交构建器

接口Execute是AsyncVoidMethodBuilder包装，状态机调用并await基类Execute(parameter)；该Task状态机Invoke缓存ExecuteMethod并await，接口内没有先调CanExecute。同步Action适配闭包先Invoke动作，再返回Task.Delay(0)，不是Task.Run后台执行。动作抛错时不会到Delay；Task与async void状态机catch Exception后分别SetException，不是吞掉/日志后正常返回。泛型公开Execute(T)另有自己的Task状态机包装，不与ICommand接口入口合并为同一函数。没有在这些执行体看到防重入、禁用或任务排队守卫。
