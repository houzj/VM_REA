StartContinuous / ContinuousRun / 工具栏Stop → 单CTS循环、轮间策略与身份限定清理

StartContinuous若已有activeRun只Cancel并return；否则经CanStartWorkflow建立CTS并开始根流程循环。每轮await RunCore后核owner，重新读取该流程StopOnNg和ContinuousRunIntervalMs；!ok且StopOnNg才停。工具栏Stop只Cancel现CTS，FinishWorkflowRun仅ReferenceEquals(activeRun,owner)时清activeRun/runningProcedureId/continuousRun并Dispose，旧运行不能清掉新owner。control.StopRequested在RunCore置continuousRun=false，但当前轮返回后仍可能进入间隔Delay，直到下一轮条件才退出；用户取消token则跳过或中断Delay。
