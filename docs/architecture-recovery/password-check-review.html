PasswordCheckWindow：字段校验、状态与挂接断点

15个原件方法、7处挂接代码；取消handler存在但挂接未定位。原件/资源摘要核对通过，未执行厂商代码、反序列化资源Value或构建XAML对象。浏览器呈现和运行绑定未验收。

Selected original contains PasswordCheckWindow, PasswordModifyWindow and PasswordSetWindow. This review retrieves only all 15 PasswordCheckWindow methods; Set/Modify bodies are now recovered separately in password-edit-review, while their BAML/runtime dependencies remain open.

CheckPassword returns nullable null for IsNullOrWhiteSpace input, true for direct string equality with OriginalPassword, false otherwise. It performs no SDK call, normalization, trimming or regex validation in that body.

OK reads passwordBox.Password and displays separate null/error labels on nullable-null or false; only true writes isPasswordOK=true and calls BaseWindow.Close. Cancel handler writes false and calls Close. No method in selected type sets DialogResult.

Connector contains seven event registration sites: preview text/key on PasswordBox and TextBox, TextBox TextChanged, CommandBinding CanExecute, and btnOk Click. btnCancel_Click body exists but no selected connector registration targets it. Missing registration is not proof of dead code or a visible Cancel control.

Preview regex is ^[0-9a-zA-Z]*$; preview key handles numeric key 18. TextChanged copies changes, uses first change Offset and only checks/removes when AddedLength>0; empty/multiple changes, deletion-only invalid text and actual routing remain unverified.

CommandBinding_CanExecute sets only Handled=true; it does not assign CanExecute. This differs from Apps.PcUI Encryption/Decryption, which set both true. Effective clipboard command availability cannot be inferred from this body alone.

IfShowPassword=true copies passwordBox to tbPassword and switches visibility; false copies back. OK always reads PasswordBox. Selected original BAML offline declarations are linked in password-baml-review; actual synchronization and default/Return behavior remain unknown.

VisionMaster and VMControls.WPF TypeRefs both resolve by assembly name/version/public-key token to the selected PasswordWindowUI identity. Script/Group callers pass different password fields and read IsPasswordOK; runtime binding and full caller chains remain unverified.
