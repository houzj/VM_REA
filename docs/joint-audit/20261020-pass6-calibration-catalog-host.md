当前共享链：`src/VisionEditor/ToolNavigation.cs` 的 `ToolGroups → LoadToolCategory → ReadCategoryTools → CreateCatalogTile` 从分类 JSON 取工具，按 `ModuleId` 查已注册 descriptor 决定是否可用；`MainWindow.xaml.cs` 构造时逐个注册标定插件；`ToolPluginRegistry.Register → ModuleRegistry.Register` 校验 manifest/descriptor 身份；`GraphEditorDocument.AddNode` 取得 descriptor 并写默认参数。用户现有 `tool-catalog.json` 未提交改动使 N图像标定、相机映射两个 `ModuleId` 从 null 变为注册值；本轮只读这个工作区事实，没有覆盖或提交该文件。`HEAD` 目录是八个标定 ID，当前工作区是十个。

`tests/CalibrationCatalogHost.Checks` 在自有离屏 WPF `MainWindow` 中真实加载“标定”分类，逐项核目录 ID、插件注册、manifest/descriptor/version、`ModuleRegistry.Create` 运行时工厂和 `GraphEditorDocument.AddNode`，最后确认图中有十个唯一节点。十项全部通过，原始 stdout `analysis/joint-audit/calibration-catalog-host/checks.log` SHA-256 `0BEB1FBB9647B008CFA18379FFE801F0612051EB0BDB9CFD58378AA13D23CEC9`，逐项端口/编辑器存在性快照 `catalog-host.json` SHA-256 `E6F1E5230863359D10A435434B07DC84CC91632D5BB348FD3826C1C739C2D3C0`。快照另证十项都至少有专用 WPF 工厂或共享配置 provider；相机映射、映射标定走后者，不能因无专用工厂误报无编辑器。复验：`dotnet run --project tests/CalibrationCatalogHost.Checks/CalibrationCatalogHost.Checks.csproj -c Release`。首次测试因测试文件缺 `System.IO` 导入未编译，失败日志保留于同目录 `first-compile-failed.log`；随后只修测试，产品未变。这个探针验证当前工作区**实例化**共享边，不验证用户交互桌面拖放、配置窗、真实执行、Group/保存重开或原版逐工具身份同一性。
